## 使用说明

不同批次的环境、奖励、动作、完成保障、训练预算和统计单位并不相同。先查对照文档，再使用对应批次数据；不能把所有`H2O+`、`MC-WM`或`CS-BAPR`名称视为同一个冻结控制器。摘要选定替换文字已登记为软SINDy与原配方RE-SAC的比较；导师Word未修改，其现有旧摘要及表4-10/4-11仍按稳定化MLP与BAPR追溯。

仓库保留已经在本地的实验数据和检查点，但大量服务器训练数据与模型没有下载。各版本结论已从现有小型服务器分析汇总和冻结图源整理，不再只登记数据位置。本次没有从服务器拉取新数据；远程位置沿用各批次的协议、派发记录和运行日志。表3-2目前只能追溯到原论文报告值，未找回逐回合原始记录。因此这不是所有实验环境、数据和权重的完整镜像。

Word、PDF、PPT、旧论文正文、全文备份及整页渲染预览由`.gitignore`排除。本地文件均保留。数据索引脚本只读Word；对照文档重建使用已归档的相邻项目小文件快照，不重新读取正在更新的相邻项目，不重新训练。

```bash
python3 scripts/index_thesis_data.py
python3 scripts/summarize_thesis_versions.py
python3 scripts/build_thesis_data_map.py
```

第一条需要本地原Word及其来源目录；后两条使用本仓库已归档索引、结果汇总和快照。没有原Word的仓库使用者可直接读取已提交的图表索引、对照文档和数据快照。实验重跑另需各批次原运行环境。

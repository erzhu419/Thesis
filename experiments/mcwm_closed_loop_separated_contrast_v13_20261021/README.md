# v13 背景水平与动作差分分离

解析 300 秒时钟、全局乘客成本率及固定源域同车物理基线沿用 v12，执行策略和 trust 不变。新增被动读出将背景与动作分开：12 列背景包含原水平项、全局成本率及非 holding 物理时长；9 列动作包含线路 holding 与六个状态交互。

完整的线路低／高动作校准块分到同一折，块编号在 issue 时捕获。每次更新只用当前已释放、预算选中的训练记录：在另一折拟合背景结果和背景可解释的动作特征，在折外残差上学习动作系数，再恢复背景水平。动作收益直接由动作项计算，背景代数相消。另用相同折外残差删除成本率动作列重拟合，仍保留成本率背景列；同时报告固定权重删成本率项及其物理单位贡献、背景相关、残差化范数与设计秩。无双折支持的早期预测保持 unsupported。

同一新流上保留 v12 联合拟合作对照，所有旧预测和完整流逐项精确复现。训练继续为 6201/6202 × 稳定／局部降速四日：各 24000 秒、50000 步初始化、285 个训练 issue、456 次 policy/trust 更新。新读出和诊断臂共用已有标签，不使用配对真值训练，不按已见结果调参。

先原生短日和双分支预检，再四日诊断，最后 seed6201 每场景、每线路两个固定状态，共12状态、24条300秒原生分支。全部状态的旧端点真值对照 v12，后缀零训练。新增7200秒后缀以及前缀秒数、标签和更新重放单列，预检另计。

重点看成本率项放大是否缓解、300秒收益方向和 regret、两状态变化及稳定场景退化。该分离是回归识别诊断，完整性或秩通过不能证明因果识别成功。独立确认不自动提交。

入口：`launch.py stage`、`launch.py preflight`、`continue_batch.py`。任务全部 high；只回收20KB以内gate和200KB以内最终汇总，不拉模型或原始轨迹。原冻结实验和已有结果保持只读。

# A1/A2/A3 正式目标适应对照，2026-10-20

本批次在独立目录开展，原 `F-FINAL-225`、原稿和 v1 smoke 结果均保留。冻结设置见 `protocol.json`，运行入口为 `launch.py` 和 `run.py`。

## 固定比较

五个训练种子 6201–6205，A1=`replay`、A2=`online`、A3=`context`。每个种子的三个分支共用其原有 50,000 步离线 IQL 初始化器，读取同一历史目标样本与同一 4,096 条源样本。历史样本共 32,768 条，包含全部 240 个真实终止尾段；历史回放按原始概率质量抽样，避免保留尾段后人为放大终止频率。初始化器原在 GPU 训练，本批 CPU 运行仅关闭 Adam 的 CUDA fused/capturable 执行选项，保留参数、优化器动量、步数与学习率。

每个目标日完整运行 24,000 秒。反馈窗口末端为 1,200、1,500、…、18,000 秒，共 57 个窗口，每窗选取 5 条不同的、已完成且延迟 30 秒后可用的正时长非终止目标记录，共 **285 条**。按到达时间选最新记录，不根据误差或成本挑选。某窗不足 5 条就记录失败，不借用未来结果。各分支在窗口后的首个决策事件处理反馈，实际处理时间和延迟保留在回执中。每包做 8 次策略更新，全天 **456 次**；A2/A3 的每个模型家族另做 10 步重拟合，初始拟合各 400 步。

本批固定源回放，不增加随策略变化的源采样，集中比较相同输入预算下的适应方法。A3 在每批重拟合后，用该批已到达结果重新计算四维残差上下文，使上下文用于后续预测；不会在重拟合清零后使 A3 退化为 A2。

## 两类证据

控制比较：5 种子 × 2 场景 × 3 分支，共 **30 个完整闭环目标日**。场景包括稳定运行，以及第 9,000 秒将共享路段 `E_J282_J328.50` 的四条机动车道限速乘以 0.65；原生 SUMO 时钟触发，策略不接收变化标志。SUMO 固定为服务器已有的 1.25.0。

预测比较：同样 5 种子 × 2 场景，共 **10 个共同数据流目标日**。每个流由冻结的同种子 IQL actor 生成；冻结历史模型参考、A2 与 A3 收到完全相同的 285 条记录。A1 没有世界模型，因此冻结模型只作为预测诊断参考。评分使用决策时已选择家族的保存预测，不能在看到标签后取两家族较小误差。

预测误差分为变化前 6,000–9,000、变化后早期 9,000–12,000、晚期 15,000–18,000 秒。控制主指标保留完整乘客账本成本，并计算同方法同种子“限速变化 − 稳定场景”在 9,000–18,000 秒的额外累计成本。恢复定义为先出现可辨认的早期退化，随后连续三个 300 秒窗口的额外成本率不高于稳定场景的 10%；没有明显退化、未恢复、失败和缺失分别报告，不记为零秒成功。统计单位为五个种子。

## 派发与小文件收集

本批经 scheduler 在 Linux CPU 节点运行，单任务一核、8 GB RAM，不占 GPU。初始化器在服务器内复制或服务器间传输，本地不下载权重、历史缓存或轨迹。只上传新增代码和已有 430 KB 源样本，汇总在服务器执行后只取 JSON。

```bash
.venv/bin/python experiments/mcwm_closed_loop_formal_20261020/launch.py status --batch campaign
.venv/bin/python experiments/mcwm_closed_loop_formal_20261020/launch.py collect
```

输入准备任务、两个原生 SUMO 预检、正式任务分别登记在 `prepare_submission.json`、`preflight_submission.json`、`campaign_submission.json`。`finalize_submission.json` 登记服务器端汇总任务：等待本批 40 个单元结束后，自动运行比较并生成 `campaign_analysis.json`，不依赖本地聊天持续运行。输出目录在服务器对应的本实验目录内；预检在 `preflight/`，正式结果在 `runs/`。汇总保留完成范围和所有失败/缺失状态。运行进度不是方法收益结论，完整配对结果到齐后再判读预测适应与控制恢复。

# 公交控制差异对齐与符号反馈修复

## 已确认的差异

旧MC-WM固定0.25分支在三种源标定条件下，分别有19/20、20/20、20/20个训练种子优于当时的Daganzo对照。双方都使用完整服务保障执行层。旧部署holding缩放系数实际为1，不是依靠缩小动作取得这一批收益。

新分支同时改变了全局事件状态、同车转换结算、离线数据、奖励及执行接口，没有使用服务保障。旧Daganzo测试平均成本为2684.64秒/人，新直接执行Daganzo为2696.81秒/人；名称相同不等于控制配置相同。新时距目标也不能只按乘客成本判断成功与否。

CS-BAPR原公交论文使用时距奖励，但公交配置关闭两项符号损失，以NAU或MLP及稳定化设置学习；10种子、500回合并按ID最佳检查点选策略。本轮则是新引入的硬符号参考、残差中心化和两项约束，两个种子、100回合末次策略。旧NAU在本轮对照中仍然有效；失败的是新增的符号适配，不是所有CS-BAPR公交版本。

## MC执行层分支

不重复训练，复用两个首位预先指定种子及已标定、高偏差两个条件的冻结策略。旧全局乘客策略补测无保障执行，新同车策略补测有保障执行。旧有保障结果和新无保障结果直接从服务器读取，不重复评估。

保障后的学习策略和Daganzo必须使用相同保障，保障前也同样如此。另加零holding、固定1.1/1.2速度系数对照，区分离站加速权限与学习策略收益。共350个完整SUMO案例，所有案例独立CPU分片。

这些实验定位执行层影响，不能冒充重新训练后的算法改进。旧策略与新策略的状态不同，因此不能从该比较单独推断状态表征的因果贡献。

## CS学习分支

保持原数据、环境、种子和100回合预算，比较四种配置：

- `numeric_old`：保留原硬参考，只加熵温度上限0.6与归一化雅可比误差。
- `smooth_hard`：同时改为单站成本参考、softmin温度0.25；不滚动两条失准线路的动力学。
- `smooth_soft`：同样使用平滑参考，但参考只进入软雅可比约束；完整参考状态动作可以学习，不再被硬参考锁定。
- `soft_no_symbolic`：与上一组使用相同中心化策略结构和数值设置，移除两项符号损失。

归一化误差为每个样本的策略与参考雅可比平方差，除以1加参考雅可比平方范数；actor与critic使用同一量。这是新损失定义，不能写成原方法不变。参考状态处的神经残差仍为零，但归一化零动作不再被误当作零额外holding。

两种奖励、两个配对种子，共16条训练、144个策略测试；另36个平滑直接反馈测试。独立ID辨识日用于记录饱和比例与雅可比尺度，不按正式测试效果修改阈值或选择种子。归一化、参考平滑与解锁完整动作逐组分离，训练完成后分别判断数值稳定与控制收益。

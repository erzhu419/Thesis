## 本轮解决什么

旧A1同时增加fresh反馈和456次更新，不能单独识别新监督的贡献；而旧A1早于统一执行F，不能直接用新的无fresh臂减旧A1。本轮在当前同一F下重新成对运行：

| 项目 | fresh | no_fresh |
|---|---|---|
| 初始化、源/历史数据 | 同一50000步初始化、4096源行、32768历史行 | 相同 |
| 目标日 | 同种子、24000秒、相同场景与外生随机种子 | 相同 |
| 反馈与优化 | 57包×5槽=285，57×8=456次更新 | 相同 |
| critic每步256槽 | 源128＋历史64＋fresh完整转移64 | 源128＋历史64＋历史完整替换64 |
| 当前s/a | 用于actor、IQL V、温度 | 同一访问与采样规则 |
| 新r/ns/dt/terminal | 用于事实Bellman监督 | 不读入、不保存在学习回放中 |
| 执行/目标Q | 同一ExecutionAction，真实TD系数1 | 相同 |
| world、trust、反事实查询 | 全部0 | 全部0 |

估计对象是**在保留当前状态/动作访问规则时，新鲜事实outcome监督的总效果**。两臂闭环轨迹允许分化，反馈内容不承诺逐条相同。相同285个采集槽不等于两臂使用相同监督，监督使用正是本轮因素。历史替换始终是一整条(s,a,r,ns,dt,terminal)，不会把旧结果拼到新状态上；两臂采样随机数消耗、优化顺序和Adam状态起点相同。world/trust收益留待后续独立归因。

## 对Astra各项意见的落实

- **时序解释**：按原准入顺序复算，7X3815的−6秒为首次负响应；16243见过−6监督后，真值为+3秒，预测约+0.5秒。没有“监督后再次负响应”的样本。两个负端点只算一个物理状态。
- **正则解释**：目标除60再乘60抵消；历史输入除60改变有效正则，线路截距也被拉向+7.5秒。单个0秒样本给出3.75秒。v21/v23最大历史作用分别0.037708/0.043119秒；只复算，不追旧留出调ridge。
- **支持与采样**：旧第三段分层按实际三段均值重分后，三线覆盖为2/1/1组，原来为3/3/1。旧回退后候选未知；新日持续统计完整窗口，不在首个可行状态后停止。第三段与实际均值、原始headway分别保留。
- **F条件**：区分floor条件成立与确实增加holding，按线路和3600/18000秒阶段记录native/tail、去floor差异。全部保留真实时钟与F。旧选中状态支持0秒，说明当次floor不实际生效；旧后缀其他事件的贡献仍未知。
- **权限**：主归因恢复事实反馈，不添加配对训练或目标反事实查询。被动历史仅取issue前已完成且已观察的区间，计数不进入学习或选样。原配对支线的查询权限单列，原失败门不改判。
- **终点**：服务时移与反转回归辅助解释；本轮提交不以服务门或稳定成本正负筛选。主终点为完整乘客账本的绝对2W+R及每名出发乘客成本，等待和乘车分别报告；未触发10%早期退化时，恢复为NA，不记作0秒。

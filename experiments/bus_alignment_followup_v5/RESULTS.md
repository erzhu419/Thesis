# 本轮完成结果

CS各训练100回合；MC复用各自5万次更新的离线初始化，进行2.5万次源仿真决策预算、2万次在线更新。
完整事件批次可使实际源决策数超过预算不足16次，更新数保持一致。没有目标SUMO在线训练。
服务器逐例检查了预算、完整时域、数值有效性和配对场景；仅回传约700 KiB摘要，无数据或权重下载。
以下百分比均由完整训练种子的平均指标计算，未筛选种子。

## CS-BAPR稳定化方法

恢复原公交论文的主要比较后，优势出现了。表中为稳定化MLP相对原始BAPR的每次结算决策平均原生时距惩罚降低率。
每格包含两个训练种子、每种子三个相同测试日；两种动作分别比较。

| 场景 | 单动作 | 双动作 |
| --- | ---: | ---: |
| 正常客流 | 69.10% | 15.50% |
| 一次5倍脉冲 | 69.79% | 16.72% |
| 重复5倍脉冲 | 68.62% | 17.11% |
| 持续5倍客流 | 65.56% | 24.51% |
| 持续10倍客流 | 58.82% | 28.56% |
| 600秒50倍冲击 | 67.16% | 23.57% |

单动作正常场景的静态计划时距误差由162.18秒降至103.00秒，降低36.49%；持续10倍降低27.10%。
69.10%的较大均值收益主要来自原始BAPR种子64002的退化，不能解释成每个种子均改善约69%；正常场景两种子的惩罚改善分别为9.65%、81.32%。
双动作稳定化MLP的原生时距奖励在两个种子的六个场景均改善。NAU对已稳定化MLP仍没有稳定的额外优势。
因此，之前“优势不明显”的首要原因确实是比较对象已经包含稳定化改进，并非原公交方法在这里完全失效。

## 上下文与符号约束

上下文基线修复相对原常数基线的符号策略，平均原生时距惩罚改善0.69%--4.28%，六个场景的静态计划时距误差均值也均降低。
但新增符号项相对同架构无符号对照，在正常、一次脉冲、重复脉冲中改善原生奖励，在持续5倍、10倍及50倍短冲击中退化。
持续10倍的两种子原生奖励均退化，尽管静态计划时距误差和乘客成本均改善；不能用这些辅助指标替代其目标指标。
乘客目标下，符号策略相对同架构无符号对照的成本均值仅降低0.011%--0.033%，不作为有实质增益的结果。
最终headway符号策略的熵温度约0.0166--0.0177，远低于0.6上限，本轮没有熵温度爆炸的证据。
修复解除了策略表示与参考导数的冲突，但未确立符号约束在公交强扰动下的独立优势；它不替代稳定化主结果。

## MC-WM时距目标

保留梯度范数上限10的候选。以下均为双动作、时距奖励、相同保障执行器和20个配对SUMO测试结果的均值；时距奖励越接近零越好，乘客成本越低越好。

| 高标定偏差场景 | 原生时距奖励 | 乘客成本（秒/人） |
| --- | ---: | ---: |
| Daganzo | -324.925 | 2684.637 |
| 原版H2O+ | -336.985 | 2749.327 |
| 同时裁剪的H2O+ | -317.113 | 2712.575 |
| 裁剪后的MC-WM | -314.579 | 2614.777 |

相对原版H2O+，MC-WM的时距惩罚降低6.65%、乘客成本降低4.89%；相对Daganzo分别降低3.18%、2.60%。两种子各自的平均时距奖励与乘客成本均胜过原版H2O+和Daganzo。
相对同时裁剪的H2O+，时距惩罚均值降低0.80%、成本降低3.61%；成本两种子均赢，时距奖励一赢一输。
MC两种子的高偏差平均执行速度现在均约1.183，之前约1.186与0.820的速度分歧消失，但holding仍有种子差异。
日志中的critic梯度范数是裁剪前的范数，约498与947不表示上限10没有生效；裁剪发生在优化器更新之前。
速度先验候选不保留为主结果：高偏差两种子的速度均退至约0.857，平均时距奖励为-360.763，差于H2O+和Daganzo。

## 论文使用与边界

建议保留原先有效的双动作乘客目标结果，配合本轮双动作时距目标的裁剪候选。原乘客目标MC-WM相对H2O+的成本改善为3.48%/4.81%，相对Daganzo为1.94%/4.13%（标定/高偏差），未被覆盖或重跑。
MC主结果围绕完整MC-WM方案与H2O+、Daganzo的比较组织，以两种奖励及动作设置下的效果展示为主。
时距目标的标定场景仅接近H2O+：裁剪MC-WM对同裁剪H2O+的时距惩罚改善0.42%，乘客成本高0.055%，不写成明显优势。
这些SUMO优势限于共同保障执行器；无保障直接执行尚没有同时胜过规则的综合结果。两种子不是20个独立训练重复，既有SUMO测试日也不是新的未见验证集。
CS的原生奖励使用动态前后车目标和相似性惩罚；静态计划时距误差采用线路固定计划目标，二者不等价，不能互换或与MC协议直接合并。
CS乘客目标仍未表现出稳定化的实质成本优势；RandomLoad的符号收益不作为公交结果。旧结果和本轮负结果全部保留，论文正文尚未修改，本轮未新增训练。

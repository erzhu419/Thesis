## 新增组合

| 动作 | 奖励 | 算法 |
|---|---|---|
| holding | 第三章脊形车头时距奖励 | H2O+、MC-WM |
| holding＋离站速度调整 | 第三章脊形车头时距奖励 | H2O+、MC-WM |
| holding＋离站速度调整 | 广义乘客时间奖励 | H2O+、MC-WM |

每组采用65001至65003三个配对训练种子，以及标定、联合50%偏差、联合75%偏差三个源场景：共54条正式训练、540条策略评估，另有20条零控制与Daganzo规则评估。每个策略使用相同十个SUMO测试案例，各评估分片独立并行。

## 接口修复

- 转换由同一车辆本站动作到下一站观测组成，状态包含该车上一次动作；不再用下一辆车的控制事件替代动作后果。未完成区间丢弃，不制造终止零奖励。
- holding范围0—60秒，双动作的速度系数范围0.8—1.2。简易仿真的标定运行时间恢复速度响应，SUMO执行相同连续系数；不重复添加基础停站服务时间。
- 时距奖励在同车下一站结算，保留第三章的大偏差20点惩罚。乘客反馈为该区间的 `-(2×候车乘客秒增量＋车内乘客秒增量)`，不把车内时间误称为仅车内等待时间。
- 两个域使用同一离线数据确定的奖励中心与尺度。时距分支的合成奖励由模型预测状态计算，避免时距与独立奖励预测相互矛盾。
- holding分支仅重组原v7训练分区；双动作在服务器分12片采集新SUMO离线数据，两种奖励共用。测试需求种子与采集种子分开。

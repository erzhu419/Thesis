# 数据预算与转移模型失配

## 问题与实施

本轮检验两件事：同样的目标离线数据和源交互预算下，世界模型辅助是否提高公交控制收益；源仿真的转移机制发生偏差时，这种方法是否比H2O+更少退化。上一轮共用50,000步既有初始化、只续训2,000步，不能用于证明完整训练更快。同条件续训耗时分别约70秒和83秒，世界模型分支另有模型拟合开销。

离线预算为48和144个完整日志回合，分别对应两个和六个完整环境块。每档从随机参数重新进行10,000步离线训练，再共用于两种方法。源交互取约4,096和16,384个决策，策略更新次数分别为512和2,048；同时发生的决策批次不拆开，因此逐项报告实际交互数。模型拟合、停止、选择和可信度学习不读取该档预算以外的目标样本；源模型只使用本分支已经计数的在线源交互。两种方法均保留原H2O+密度比修正与相同部署规则。

## 转移机制偏差

在144回合离线数据和较高源交互预算下，保持SUMO评价及目标日志不变，对源仿真增加以下场景。

| 场景 | 源端改动 |
| --- | --- |
| 已标定参照 | 原有经验运行时间、OD及上下客参数 |
| 行驶速度偏差 | 有效路段平均速度降低25%，相应延长物理运行时间 |
| OD强度偏差 | 各OD流量增加25%，实际改变到达和排队过程 |
| 路口密度偏差 | 增加相当于原信号路口密度25%的额外遭遇，按原周期和绿灯比例生成延误 |
| 停站时间偏差 | 上下客所需的基础停站时间增加25%，不改变控制器追加停站的动作范围 |
| 联合25%偏差 | 上述四项同时施加 |
| 联合50%偏差 | 速度降低50%，OD、额外路口密度及基础停站时间偏差扩大到50% |
| 无经验运行时间标定 | 关闭经验路段时间采样，使用原简易仿真的速度、加减速及信号延误机制 |

已标定分支的经验运行时间包含既有路口延误，额外路口试验仅增加超出基准密度的遭遇，不重复加入全部信号延误。最后一个场景只取消经验运行时间标定，不等于连路网、OD、上下客知识也完全未知。首轮OD试验改变总强度，尚不改变目的地空间分布。

## 输出与范围

每个策略在正常和1.25倍需求下各运行一个新的完整SUMO环境块，服务时域24,000秒。先绘制离线数据与交互预算曲线，再给出各物理失配下的绝对乘客时间和相对本方法已标定参照的退化幅度。完成率继续报告；此前0.011个百分点的变化不作为停止补充实验的理由。

本轮采用一个训练种子，是针对博士论文论证的小规模对照。既有源仿真的历史标定保持共用，离线预算指本轮策略及模型学习可访问的目标日志量，不是原仿真建设的全部信息成本。全部新增代码和结果保存在Thesis，原论文实验不改。

当前进度：协议和源物理干预已实现，正在训练。第一档离线前缀曾因保存接口缺少元数据参数退出，已修正并按相同随机种子重新开始；未据此改变方法或预算。

# 附录B BAPR动作补偿与模式误判的数学证明

[P3526] 附录B BAPR动作补偿与模式误判的数学证明

[P3527] 本附录对应 BAPR 的持久执行器模式与策略重参数化机制。证明围绕一个核心问题展开：若不同环境模式仅改变动作坐标，是否能够保留同一参考模式下的策略，通过坐标补偿恢复参考模式的执行；当模式识别不完全正确时，动作误差又如何进入长期回报差异。

[P3528] 论证依次包括有界动作的补偿可行性、极性变换下的逐路径等价、已有信息与模式可辨识性、动作加权的模式误差，以及有限噪声模型中的性能差恒等式与条件上界。

[P3529 M003791] B.1 基本条件。设受控动力学系统的动作空间维数为 $n_{a}$，归一化控制指令空间为

[P3531 式(B-1) M003792] $\mathcal{A = \lbrack -}1,1\rbrack^{n_{a}}.$

[P3532 式(B-1)] (B-1)

[P3533 M003793,M003794] 逐坐标截断映射记为 $clip$，其第 $j$ 个分量为

[P3535 式(B-2) M003795] $clip(a)_{j} = {clip}_{1}(a_{j}),\quad\text{其中}\quad{clip}_{1}(x) = max\{ - 1,min\{ x,1\}\}.$

[P3536 式(B-2)] (B-2)

[P3537 M003796,M003797,M003798,M003799,M003800] 模式 $z$ 的对角执行器增益矩阵为 $G_{z} = diag(g_{z,1},\ldots,g_{z,n_{a}})$，其对角元素按动作坐标编号。控制指令 $a\mathcal{\in A}$ 先经增益矩阵形成名义控制信号 $v_{nom} = G_{z}a$，再与执行噪声 $\varepsilon$ 叠加并截断，得到实际执行信号

[P3539 式(B-3) M003801] $u_{exec} = clip(v_{nom} + \varepsilon).$

[P3540 式(B-3)] (B-3)

[P3541 M003802,M003803,M003804,M003805,M003806,M003807,M003808] 环境物理状态转移和即时奖励分别由 $F_{phys}(x_{phys},u_{exec},e)$ 与 $r(x_{phys},u_{exec},e)$ 给出，其中 $x_{phys}$ 表示物理状态，$e$ 为外生随机事件。不同模式共用同一物理演化机理 $F_{phys}$ 和奖励函数 $r$，模式间的差异仅由执行器增益矩阵 $G_{z}$ 体现。

[P3542 M003809,M003810,M003811] 设观测映射为 $o(x_{phys})$，参考模式（记为 $ref$）下的基准策略为 $\mu_{ref}$，其输出的参考动作为

[P3544 式(B-4) M003812] $a^{ref}(x_{phys}) = \mu_{ref}\left( o(x_{phys}) \right)\mathcal{\in A.}$

[P3545 式(B-4)] (B-4)

[P3546 M003813,M003814,M003815] 在参考模式下直接执行时，名义信号为 $G_{ref}a^{ref}(x_{phys})$。在另一模式 $z$ 下，希望通过选择补偿指令 $a_{z}(x_{phys})$，使得

[P3548 式(B-5) M003816] $G_{z}a_{z}(x_{phys}) = G_{ref}a^{ref}(x_{phys}).$

[P3549 式(B-5)] (B-5)

[P3550 M003817] 式(B-5)描述了名义信号的代数恢复条件；考虑到控制指令受有界区间 $\mathcal{A}$ 截断约束，以下先讨论其可行性条件。

[P3551] B.2 补偿条件。

[P3552 M003818] 引理B.1。 对任意实数 $x$，有

[P3554 式(B-6) M003819] ${clip}_{1}(x) = x\quad \Leftrightarrow \quad - 1 \leq x \leq 1.$

[P3555 式(B-6)] (B-6)

[P3556 M003820] 证明。截断映射的值域为 $\lbrack - 1,1\rbrack$，且在该闭区间内为恒等映射，充分性与必要性均由定义直接得到。证毕。

[P3557] 逐坐标应用该引理，立得

[P3559 式(B-7) M003821] $clip(a) = a\quad \Leftrightarrow \quad a\mathcal{\in A.}$

[P3560 式(B-7)] (B-7)

[P3561 M003822,M003823,M003824] 定理B.1。 设 $G_{act} = diag(g_{1},\ldots,g_{n_{a}})$，每个 $g_{j} \neq 0$，期望实现的名义目标信号为 $v_{nom}^{*}$。令逆指令为

[P3563 式(B-8) M003825] $a_{inv} = G_{act}^{- 1}v_{nom}^{*},\quad\quad a_{inv,j} = v_{nom,j}^{*}/g_{j}.$

[P3564 式(B-8)] (B-8)

[P3565] 则

[P3567 式(B-9) M003826] $G_{act}\, clip(a_{inv}) = v_{nom}^{*}\quad \Leftrightarrow \quad a_{inv}\mathcal{\in A.}$

[P3568 式(B-9)] (B-9)

[P3569 M003827,M003828,M003829,M003830,M003831] 证明。 因 $g_{j} \neq 0$，逐坐标有 $g_{j}(v_{nom,j}^{*}/g_{j}) = v_{nom,j}^{*}$，即 $G_{act}a_{inv} = v_{nom}^{*}$。若 $G_{act}\, clip(a_{inv}) = v_{nom}^{*}$，则 $G_{act}\, clip(a_{inv}) = G_{act}a_{inv}$，从而

[P3571 式(B-10) M003832] $g_{j}\left( {clip}_{1}(a_{inv,j}) - a_{inv,j} \right) = 0$

[P3572 式(B-10)] (B-10)

[P3573 M003833,M003834,M003835,M003836,M003837,M003838,M003839] 对每个 $j$ 成立。非零增益意味着 ${clip}_{1}(a_{inv,j}) = a_{inv,j}$，由引理B.1得到 $a_{inv,j} \in \lbrack - 1,1\rbrack$，即 $a_{inv}\mathcal{\in A}$。反之，若 $a_{inv}\mathcal{\in A}$，截断映射不改变 $a_{inv}$，故 $G_{act}\, clip(a_{inv}) = G_{act}a_{inv} = v_{nom}^{*}$。证毕。

[P3574 M003840] 代入 $v_{nom}^{*} = G_{ref}a^{ref}$，精确补偿的可行性条件为

[P3576 式(B-11) M003841] $G_{z}^{- 1}G_{ref}a^{ref} \in \lbrack - 1,1\rbrack^{n_{a}}.$

[P3577 式(B-11)] (B-11)

[P3578 M003842,M003843,M003844,M003845] 例如单维增益 $g_{z} = 1/2$、参考增益为1、参考动作为 $a^{ref} = 1$ 时，逆指令为2，经区间 $\lbrack - 1,1\rbrack$ 截断后实际名义信号仅为 $1/2$，无法恢复目标信号1。

[P3579 M003846,M003847,M003848,M003849,M003850] 将对角元素仅取 $+ 1$ 或 $- 1$ 的增益矩阵称为极性变换。对任意极性变换矩阵 $G_{z}$，以 $I_{n_{a}}$ 表示 $n_{a}$ 阶单位矩阵，有

[P3581 式(B-12) M003851] $G_{z}^{2} = I_{n_{a}},\quad\quad G_{z}^{- 1} = G_{z}.$

[P3582 式(B-12)] (B-12)

[P3583 M003852,M003853,M003854] 定理B.2。 若当前模式 $G_{z}$ 与参考模式 $G_{ref}$ 均为极性变换，且 $a^{ref}\mathcal{\in A}$，则补偿指令

[P3585 式(B-13) M003855] $a_{z} = G_{z}G_{ref}a^{ref}$

[P3586 式(B-13)] (B-13)

[P3587 M003856] 仍属于 $\mathcal{A}$，并满足

[P3589 式(B-14) M003857] $G_{z}a_{z} = G_{ref}a^{ref}.$

[P3590 式(B-14)] (B-14)

[P3591 M003858,M003859,M003860] 证明。 每个分量为 $a_{z,j} = g_{z,j}g_{ref,j}a_{j}^{ref}$。两个符号的乘积为 $\pm 1$，故 $|a_{z,j}| = |a_{j}^{ref}| \leq 1$，即补偿指令不越界；同时

[P3593 式(B-15) M003861] $g_{z,j}a_{z,j} = g_{z,j}^{2}g_{ref,j}a_{j}^{ref} = g_{ref,j}a_{j}^{ref}.$

[P3594 式(B-15)] (B-15)

[P3595] 逐坐标合并即得式(B-14)。证毕。

[P3597 M003862,M003863] 引理B.2。 若两个名义信号满足 $v_{nom,1} = v_{nom,2}$，且经历同一执行噪声 $\varepsilon$，则

[P3599 式(B-16) M003864] $clip(v_{nom,1} + \varepsilon) = clip(v_{nom,2} + \varepsilon).$

[P3600 式(B-16)] (B-16)

[P3601] 证明。 两个截断输入恒等，映射输出亦恒等。证毕。

[P3604 式(B-17) M003869] $u_{exec,k} = clip\left( v_{nom}\left( k,x_{phys,k} \right) + \varepsilon_{k} \right),\quad\quad$

[P3605 式(B-17) M003870] $x_{phys,k + 1} = F_{phys}(x_{phys,k},u_{exec,k},e_{k}).$

[P3611 M003873,M003874] 引理B.3。 若两个信号规则对所有 $k,x_{phys}$ 满足 $v_{nom,1}(k,x_{phys}) = v_{nom,2}(k,x_{phys})$，则从同一初始状态、使用同一噪声与事件序列运行任意有限步数后，末状态及累计奖励完全相同。

[P3613 M003876,M003877,M003878,M003879,M003880] 定理B.3。 设 $z_{k}$ 为任意给定模式序列，所有 $G_{z}$ 均为极性变换。比较以下两个控制过程：参考过程始终产生名义信号 $G_{ref}a^{ref}(x_{phys,k})$；切换过程在每步获知真实模式 $z_{k}$ 并执行指令 $G_{z_{k}}G_{ref}a^{ref}(x_{phys,k})$。若初始状态及外生噪声序列相同，则两过程在任意有限时域内逐路径具有相同的物理状态、执行量、即时奖励和累计回报。

[P3614] 证明。 对任意步数与状态，切换过程的名义信号为

[P3616 式(B-19) M003881] $G_{z_{k}}\left( G_{z_{k}}G_{ref}a^{ref}(x_{phys}) \right) = G_{ref}a^{ref}(x_{phys}),$

[P3617 式(B-19)] (B-19)

[P3618] 与参考过程完全一致。由引理B.3，任意有限前缀步数的末状态、执行量与累计回报逐项相同。证毕。

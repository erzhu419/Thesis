# 公交世界模型补充试验

本目录独立于原论文工程，只读复用H2O+的公交状态编码器、事件采样器、源仿真和本地SUMO日志。前置模型协议见 `protocol_v1.json`，模型结果见 `runs/pilot_v1/model_results.json`；后续公交闭环比较见下节。公交适配不等同于原通用任务实现的完整复现。

```bash
python3 -m pytest -q experiments/mcwm_bus/test_model.py
python3 -u experiments/mcwm_bus/data.py --stage all --out experiments/mcwm_bus/runs/repeat_v1
CUBLAS_WORKSPACE_CONFIG=:4096:8 python3 -u experiments/mcwm_bus/run_pilot.py --out experiments/mcwm_bus/runs/repeat_v1
python3 experiments/mcwm_bus/terminal_audit.py
```

数据按完整环境块划分。每个目标轨迹无放回抽取64个非终止跨批次转移；源仿真每个完整服务日用蓄水抽样保留4096个对应转移。批内转移单独验证，不进入预测误差。抽样不能用于估计完整回合乘客收益。

每个模型族有3个集成成员，各训练400步、每100步按停止集选权重；这不是3个独立控制训练种子。目标直接模型与残差模型使用相同的小批量索引和目标更新预算。源模型额外训练400步，残差模型冻结该源模型并学习输出修正。各连续头的标准化参数只由源拟合集估计，所有模型使用相同参数。

六类损失依次为：时长与成本的对数值及系统人数增量的标准化均方误差、局部连续量的标准化均方误差、事件数交叉熵、线路交叉熵、站点交叉熵、邻车标志二元交叉熵。局部损失只在真实有效槽位上评分。预测时所有头只接收当前状态和动作，不读取真实下一事件；真实掩码仅用于损失计算。校准集按六类损失的等权均值选择残差或直接模型，再评价两个模型测试块。无条件边际模型不参与选择。

前置模型输出中的成本误差单位为广义乘客秒，不是策略回报。终止段未进入模型拟合；独立稀疏残差组件尚未移植。后续可信度学习及SUMO闭环评价单独实施。再次探索模型结构时，本轮两个模型测试块应视为已使用的开发证据。

## 小规模公交闭环补充

`control_protocol_v1.json` 为后续闭环配置。复用已有离线初始化，比较冻结策略、仅目标日志续训、源仿真混合续训和世界模型辅助续训。后三组新增2,000次策略更新及2,500次价值更新；两组混合方法共用三个完整源服务日的41,039条转移。模型辅助分支的额外价值更新中，75%为实际回放损失、25%为生成样本的可信度加权损失，权重不改变奖励值。

模型预测非终止一步转移，离散头按预测分布采样，连续头保持原规范化物理范围。可信度网络复用MC-WM的QDeltaBellman，信任传播系数0.9与公交成本的无折扣累计分开定义。终止样本只取自目标日志及完整源仿真，不以非终止模型伪造终止奖励。原始目标数据均匀抽取150,000条用于本轮续训，其中有10条终止转移；完整源回放含3条终止转移。

```bash
python3 -u experiments/mcwm_bus/run_control.py
/home/erzhu419/anaconda3/envs/LSTM-RL/bin/python -u experiments/mcwm_bus/evaluate_control.py
python3 experiments/mcwm_bus/summarize_control.py
```

世界模型沿用前置试验的三个集成成员和校准选择；没有另行寻找更优模型或检查点。原离线初始化见过全部十个原始环境块，故前置模型测试不再解释为整条控制流程的留出检验。闭环使用本组新生成的共同SUMO场景，需求倍率1.0与1.25、两个环境块、四种策略，共16个完整服务回合。输出只保留小型汇总及五分钟附近的事件时刻采样，不保存逐秒轨迹。

16个回合现已完成，结果见`runs/control_v1/公交闭环补充结果.md`及同目录中文对照图。世界模型辅助相对源仿真续训的配对平均时间下降为0.134%，四组中两组改善，完成率平均降低0.011个百分点；该结果不支持一致或明显增益。

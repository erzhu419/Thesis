## 目录

| 目录 | 材料 |
| --- | --- |
| `experiments/` | 训练与评估代码、协议、派发记录、本地已有逐例结果、权重与分析汇总；包含成功、失败及未采用分支 |

## 使用说明

不同批次的环境、奖励、动作、完成保障、训练预算和统计单位并不相同。先查对照文档，再使用对应批次数据；不能把所有`H2O+`、`MC-WM`或`CS-BAPR`名称视为同一个冻结控制器。最新软SINDy结果虽已选定，尚未写入此次Word。

仓库保留已经在本地的实验数据和检查点，但大量服务器训练数据与模型没有下载。本次没有从服务器批量拉取任何数据；远程位置沿用各批次的协议、派发记录和运行日志。表3-2目前只能追溯到原论文报告值，未找回逐回合原始记录。因此这不是所有实验环境、数据和权重的完整镜像。

Word、PDF、PPT、旧论文正文、全文备份及整页渲染预览由`.gitignore`排除。本地文件均保留。数据索引脚本只读Word；构建对照文档时会复制已存在的相邻项目小文件，不重新训练或改动相邻项目。

```bash
python3 scripts/index_thesis_data.py
python3 scripts/build_thesis_data_map.py
```

这两条命令需要本地原Word及其来源目录；没有原Word的仓库使用者可直接读取已提交的图表索引、对照文档和数据快照。实验重跑另需各批次原运行环境。

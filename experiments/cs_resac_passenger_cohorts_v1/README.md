# 原计划乘客的冲击分组评估

固定既有乘客奖励、单驻站动作的RE-SAC与稳定化感知机CS-BAPR末次演员，不训练、不覆盖旧结果，不修改Word。

两种算法、两个训练重复、三个共同评价日、正常与短时50倍冲击，共24次独立评估。基础客流与额外49倍客流分别生成；同一评价日共享基础乘客及冲击新增乘客，同刻同OD到达随机交错。冲击为3600至4200秒，评价截止18000秒。

主统计为原计划乘客的窗口内平均候车时间、车内时间、广义时间与完成率，并分别列出冲击前、冲击期间、冲击后到达的原计划乘客。用每种算法自身的无冲击结果计算变化。时间按乘客出现、上车、抵达时间计算并截于评价终点，而非只纳入完成出行者。

这是新增的配对诊断，不是在旧混合客流结果中事后拆组。新需求随机流独立于道路随机流，数值不能直接拼接到旧表中。

运行顺序：`python test_cohorts.py`，`python launch.py stage`，`python launch.py preflight`，预检通过后`python launch.py submit`，`python launch.py collect`。正式任务不固定节点、无GPU需求，允许全部十台Linux节点。冻结输入在服务器复制，逐回合小JSON在服务器归并分析，本地仅回传分析汇总。

# 第3章 平稳随机环境下基于单智能体鲁棒强化学习的公交车队驻站控制

[P0917] 第3章 平稳随机环境下基于单智能体鲁棒强化学习的公交车队驻站控制

[P0918] 城市常规公交系统在日常运营中普遍面临路段通行波动、交叉口随机信号延误与站点乘客泊松到达等内生随机扰动。在双向发车、按时刻表排班且沿线每站均可实施附加驻站的运营模式下，局部站点的微小行车延误极易通过“前向时距拉大—站台候车客流积聚—必要上下客服务时间延长”的正反馈循环沿线路逐站放大，诱发严重的公交串车并加剧乘客候车负担。在尚未预先获取目标运营环境历史交互数据的初始研究阶段，驻站控制策略只能依托仿真环境在客流与路况基础统计规律保持平稳、但单次运营实现随机波动的条件下开展在线学习。此时，双向时刻表跨班次周转排班不仅造成全天主力车辆与高峰支援车辆积累的交互样本规模悬殊，而且随运营进程逐站累积放大的车头时距方差与高维状态—动作空间的局部样本稀疏性，会使基于时序差分自举的动作价值估计同时遭受环境偶然随机噪声污染与未知驻站动作认知高估的双重失真。围绕上述公交运行特征与价值评估瓶颈，本章建立融合车辆、站点、运行方向与运营时段可学习类别特征嵌入的全车队参数共享驻站控制策略[87]，提出鲁棒集成软演员评论家方法（Robust Ensemble Soft Actor-Critic，RE-SAC）[119]，通过协同引入目标网络权重范数正则与价值集成分歧保守评价抑制两类不确定性干扰，并在双向单线路与长沙多线路共线走廊场景中系统揭示车队共享表征、奖励函数结构与鲁棒价值学习的交通控制机理。

[P0919] 3.1 问题描述

[P0920 M000511] 公交车队的沿线串车形成是一个典型的正反馈放大过程：当某辆运营车辆受路段拥堵或信号阻滞发生延误时，其与前车之间的前向车头时距随之拉大，下游沿线各站在这一拉长的间隔期内积聚了更多候车乘客，导致该车进站后的必要上下客服务时间延长；与此同时，紧随其后的同线路车辆因沿途候车需求减少而停站耗时缩短、行驶加快，逐步逼近前车，使局部的随机运行扰动沿线路逐站自我放大。本章研究双向发车、按时刻表排班运行线路上的车队逐站附加驻站控制问题，基本运营设定如下：上、下行两个方向均按计划间隔发车（双向单线路场景取360秒计划间隔，双向发车时刻错开180秒），车辆完成单程班次到达终点站后，按既定时刻表跨班次周转复用以执行后续班次；车辆在沿线任意站点完成必要的乘客上下车服务后，控制器可在 $\lbrack 0,60\rbrack$ 秒范围内决策附加驻站时长；控制过程保持既定线路走向、班次发车时刻表与交叉口信号配时不变。控制优化目标分为两类：其一面向车头时距规律性，通过计划间隔偏差（实际车头时距与时刻表规定计划间隔之差的绝对值）与前后车头时距不均衡度（前向与后向车头时距之差的绝对值均值）评价运行间隔对计划的跟踪精度与对称均衡程度；其二面向乘客出行服务，通过人均广义时间成本（两倍候车时间与一倍车内时间之和，按规定评价时域内进入系统的全部出行乘客人均计算）衡量全系统的乘客时间代价。

[P0921] 由于未成熟的强化学习驻站策略无法在实际运营车队上反复开展试错探索，策略训练必须依托仿真环境完成；而在本章所研究的基础阶段，目标运营环境的历史运行数据尚未预先获得，仿真与实际使用环境之间的潜在分布偏移无法借助目标域数据直接校正，策略只能依靠自身的经验表征与内生鲁棒性抵御不确定性干扰[10]。本章所界定的“平稳随机（Stationary Stochastic）”环境具有明确的统计含义：给定线路、站点位置、运行方向与运营时段后，支配乘客随机到达与道路车辆行驶的基础条件概率分布（如分时泊松客流到达率与路段速度分布参数）在训练与评价期间保持恒定，但每一次具体运营日实现的客流到达序列与路段行程时间仍然随机波动。这一平稳性假设并不要求全天平峰与高峰具有相同的客流需求（已知的日内时变峰谷规律可通过时段类别特征予以表征），也不要求不同运行日产生完全相同的运行轨迹；至于外部客流结构或道路通行规律本身发生未知突变或长期漂移的非平稳情形，则留待第4章专门探讨。

[P0922] 即便在基础统计规律保持平稳的随机环境中，双向逐站驻站强化学习仍面临车队个体经验失衡与动作价值估计失真两重严峻挑战。首先，在经验组织层面，按时刻表双向发车且车辆可跨班次复用时，车队中不同物理车辆在全天承担的班次任务量并不均等：全天连续周转的主力车辆可积累大量到站决策样本，而仅在早晚高峰上线支援的机动调配车辆一天仅执行少量班次，各车能够获取的交互经验规模悬殊。若按传统多智能体方式为每辆车独立训练一套策略网络，经验匮乏的车辆训练周期过长且极易陷入局部退化，而个别车辆的异常驻站动作又会通过车头时距耦合波及全线后续车辆；反之，若简单令全车队共用一个不含身份与时空背景的普通网络，又会将不同站点客流密度、不同运营时段及不同周转阶段下的相近车头时距误判为完全相同的控制状态。因此，必须以车队共享方式组织单智能体学习，由同一套策略与价值网络依次处理全车队异步到站事件，同时引入车辆、站点、方向与时段的可学习类别特征嵌入以保留控制对象的异质性[87]。

[P0923] 其次，在价值评估层面，平稳随机运行下的逐站序贯决策结构会显著放大偶然不确定性（Aleatoric Uncertainty）与认知不确定性（Epistemic Uncertainty）对动作价值估计的干扰[100,101]。在全天运营过程中，车头时距与车辆到站时刻等连续状态变量的方差随站点推进与班次接续呈累积增大趋势：上游的随机客流起伏与信号延误经由上下客服务时间与车头时距递推关系不断叠加至下游状态，致使运营越往后推进，后继状态分布越发散。SAC等基于时序差分自举的强化学习算法利用后继状态的价值估计构造当前动作的价值回归目标[63]；当后继状态受环境内生随机性驱动而剧烈波动、且高维状态—动作空间存在大量样本稀疏区域时，自举价值更新将同时面临两类性质截然不同的估计失真机制：

[P0924 M000512] 在环境内生随机波动（偶然不确定性）剧烈的运行区域，高敏感度的后继价值函数会将状态随机扰动放大为自举目标噪声与乐观偏差。由于泊松客流到达与路口信号延误具有固有随机性，同一驻站动作在不同运行次序下会转移至存在随机偏移的后继状态 $s'$；若目标价值网络的参数范数过大、局部映射斜率过陡（即关于状态度量的Lipschitz常数过大），后继状态的偶然随机偏移将在自举求值时被剧烈放大，使回归目标受到高方差随机噪声的严重污染，并经由贝尔曼自举链条逆向传播，破坏价值学习的平稳性与动作评价的准确性。

[P0925] 在训练样本覆盖稀疏的边缘状态—动作区域（认知不确定性显著区域），模型知识匮乏极易引发对未知驻站动作的系统性高估（Overestimation）。受限于有限交互样本对高维连续状态—动作空间的覆盖密度，部分极少访问的驻站时长组合缺乏充足的转移数据支撑；单一或双价值网络在这些未知区域极易因个别偶然的高回报样本或神经网络函数外推误差而产生虚假的高估值，进而诱导策略网络盲目偏向缺乏可靠经验支撑的劣质驻站动作。

[P0926] 上述两类价值估计失真源于不同的统计机制——前者源于后继状态随机转移扰动在陡峭价值曲面上的传播放大（偶然不确定性），后者源于有限样本覆盖不足导致的局部参数认知匮乏（认知不确定性），无法依靠单一的正则化手段同时化解。若仅采用价值网络集成并惩罚成员间分歧（即仅抑制认知不确定性），在各价值网络成员共享同一高方差回放池的条件下，环境随机扰动引起的较大目标震荡仍会导致全集成同步发散；反之，若仅采用网络权重范数正则限制价值函数的全局光滑度（即仅抑制偶然扰动敏感度），由于权重范数只约束网络全局参数而不感知具体输入状态—动作对的样本密度，学习器将无法识别并规避训练分布之外的高风险未知动作。因此，对动作价值估计的修正必须做到“双源解耦、协同施策”：一方面依据Wasserstein距离分布鲁棒对偶理论，引入目标网络权重范数正则化项约束后继状态价值函数对随机状态扰动的Lipschitz敏感度以稳定自举目标；另一方面引入目标与在线价值集成分歧惩罚项精准识别并压低经验稀疏区域的高分歧动作评价。上述问题诊断构成了本章提出融合权重范数正则与集成分歧惩罚的RE-SAC鲁棒强化学习方法的出发点[119]，本章整体研究框架如图3-1所示。

[P0929] 3.2 模型构建

[P0930] 3.2.1 基本条件与场景设定

[P0931 M000513,M000514,M000515,M000516,M000517,M000518,M000519,M000520] 本章在第2.7节建立的事件决策统一模型框架下，构建面向平稳随机环境的车队共享驻站控制模型。记全车队异步事件序列中某车辆在第 $i$ 次有效到站决策时的运行观测为 $\mathbf{o}_{i}$，结合离散类别特征构成完整状态 $s_{i}$，车队共享策略网络 $\pi_{\theta}(a_{i} \mid s_{i})$ 据此输出附加驻站时长 $a_{i} \in \lbrack 0,60\rbrack$（单位：秒）；当 $a_{i} = 0$ 时，表示车辆在完成必要上下客服务后不再作额外控制性停留，满足出站通行条件即可驶离站台。车辆完成单程班次返回终点站后，按预设时刻表跨班次周转承担后续发车任务，仅当终点站无可用周转车辆时方由场站补充待命车辆上线。一条完整的状态转移数据由四元组 $(s_{i},a_{i},r_{i},s_{i + 1})$ 构成，连接同一辆物理公交车在相邻两次有效到站决策时的状态、动作与期间累计奖励。本章所称的“单智能体（Single-Agent）”控制，是指由单一中央学习器统一维护一套策略网络与一套集成价值网络，依次处理全车队所有车辆的异步到站事件并将转移数据汇入同一个共享经验回放池 $\mathcal{D}$，不为每辆公交车单独维护独立的决策网络，亦不引入多智能体联合价值分解或显式车际通信协议。

[P0932 M000521,M000522,M000523,M000524] 在实验场景配置上，本章主要依托快速公交仿真的双向单线路场景开展算法训练、稳定性诊断与多因素消融实验，并进一步在基于长沙市6条双向骨干线路实测资料校准的多线路快速公交仿真场景中开展算法横向验证。双向单线路场景共设置22个物理站点（两端站点为首末站，含上下行共42条有向站间路段），上、下行方向均按 $h_{s} = 360$ 秒的固定计划间隔发车，且两方向的发车时刻对称错开180秒；分时客流OD需求覆盖06:00至19:00共14个小时时段，乘客按各时段对应到达率的泊松过程随机生成并立即进入候车队列；各向路段的行程速度在分时设定均值基础上叠加标准差为 $1.5\text{ m/s}$ 的高斯随机扰动；单回合固定策略评价时域为 $24,000$ 秒，且在附加驻站执行期间车辆关门不进行额外的乘客上下车交换。多线路验证场景则覆盖长沙市7、102、122、311、406和705路共6条双向线路（12个运行方向、389个计划班次、353个物理站点），单回合评价时域为 $18,000$ 秒，详细场景资料见第2.6节。

[P0933] 3.2.2 异步事件决策过程与经验回放机制

[P0934 M000525,M000526,M000527,M000528,M000529,M000530,M000531,M000532,M000533] 公交车辆在执行单程班次任务时，沿站点序列依次经历路段行驶、进站停靠、必要上下客服务、附加驻站控制与出站驶离五个物理环节。设同一运行方向的第 $i$ 个班次在沿线第 $j$ 个站点的实际到站时刻与实际离站时刻分别为 $y_{i,j}^{a}$ 与 $y_{i,j}^{d}$，在该站发生的必要上下客服务耗时、附加驻站控制时长、服务与驻站结束后因出站汇入条件受限产生的驶离等待时间以及驶往下一站 $j + 1$ 的站间道路行驶时间分别为 $d_{i,j}^{svc}$、$a_{i,j}$、$d_{i,j}^{exit}$ 与 $d_{i,j}^{run}$，则车辆在相邻两站之间的到离站时刻满足如下递推方程：

[P0936 式(3-1) M000534] $y_{i,j}^{d} = y_{i,j}^{a} + d_{i,j}^{svc} + a_{i,j} + d_{i,j}^{exit},\quad\quad y_{i,j + 1}^{a} = y_{i,j}^{d} + d_{i,j}^{run}$

[P0937 式(3-1)] (3-1)

[P0938 M000535,M000536,M000537,M000538,M000539,M000540,M000541,M000542,M000543] 对于同一线路、同一运行方向的相邻两个班次 $i$ 与 $i + 1$（班次 $i$ 在前、班次 $i + 1$ 在后），记后车 $i + 1$ 相对于前车 $i$ 在站点 $j$ 的实际前向车头时距为 $h_{j} = y_{i + 1,j}^{a} - y_{i,j}^{a}$。将两班次在站点 $j + 1$ 的到站时刻表达式(3-1)相减，可得前向车头时距沿线路向下一站传播的动力学递推关系：

[P0940 式(3-2) M000544] $h_{j + 1} = h_{j} + \left( d_{i + 1,j}^{svc} - d_{i,j}^{svc} \right) + \left( a_{i + 1,j} - a_{i,j} \right) + \left( d_{i + 1,j}^{exit} - d_{i,j}^{exit} \right) + \left( d_{i + 1,j}^{run} - d_{i,j}^{run} \right)$

[P0941 式(3-2)] (3-2)

[P0942 M000545,M000546,M000547,M000548,M000549,M000550] 式(3-2)给出了逐站驻站控制的序贯耦合关系：下游站点 $j + 1$ 的前向车头时距 $h_{j + 1}$，由当前站点车头时距 $h_{j}$ 以及相邻两班次在必要服务耗时、附加驻站时长、出站等待与站间行驶四个环节的时间差共同决定。在当前决策时刻，控制器虽然只能直接决定本车的附加驻站时长，但该驻站动作一旦执行，不仅直接改变式(3-2)中的控制项，还会通过推迟本车抵达下游站点 $j + 1,j + 2,\ldots$ 的时刻改变本车与后车在下游各站面临的候车人数及必要上下客服务时间 $d_{\cdot ,j + 1}^{svc}$，故单次驻站动作的优劣必须结合后续多站点的长期累积反馈加以评估。同时，当本车在站点 $j$ 触发决策时，后车尚未抵达本站，事后方能结算的真实后向间隔不可作为实时输入；本章按第2.7.2节规定，直接以紧随本车的后车在其最近一次停靠上游站点时观测到的前向车头时距作为当前后向车头时距的因果观测值。事件触发的公交运行闭环控制过程如图3-2所示。

[P0945 M000551,M000552,M000553,M000554,M000555,M000556,M000557,M000558,M000559,M000560,M000561,M000562] 由于车队中多辆公交车在不同物理时刻异步进站触发决策，系统时钟上相邻的两次决策事件往往分属两辆不同的运营车辆。为确保状态转移真实反映单车动作与其后续运行后果的因果联系，经验回放池采用按车暂存、延时配对的写入机制：当车辆 $v$ 在其第 $i$ 次受控到站时刻完成决策 $(s_{v,i},a_{v,i})$ 后，系统将该状态—动作对存入车辆 $v$ 专属的临时缓存槽；在此期间，其他车辆 $v'$ 的到站事件照常调用策略网络并各自暂存；直至车辆 $v$ 驶达下游下一受控站点（含终点周转后执行下一班次的首个受控站点）触发第 $i + 1$ 次决策并获得新状态 $s_{v,i + 1}$ 与区间累计奖励 $r_{v,i}$ 时，系统方才将配对完成的转移数据 $\xi_{v,i} = (s_{v,i},a_{v,i},r_{v,i},s_{v,i + 1})$ 正式推入全车队共享经验回放池 $\mathcal{D}$。回合运行到达规定终点时刻 $T_{hor}$ 时，尚在途中未触发后继到站事件的末次暂存动作因缺乏后继状态而不写入经验池。

[P0946 M000563,M000564,M000565,M000566,M000567,M000568,M000569] 设全车队共享经验回放池 $\mathcal{D}$ 中当前共存储 $N = \sum_{v}^{}N_{v}$ 条完整转移数据，其中由车辆 $v$ 贡献的样本条数为 $N_{v}$。当学习器每次以均匀无偏采样方式抽取批量大小为 $B$ 的小批量（Mini-Batch）样本开展梯度更新时，小批量中来自车辆 $v$ 的样本数量 $B_{v}$ 的数学期望为：

[P0948 式(3-3) M000570] $\mathbb{E}\left\lbrack B_{v} \right\rbrack = B \cdot \frac{N_{v}}{N}$

[P0949 式(3-3)] (3-3)

[P0950 M000571,M000572] 式(3-3)表明，在双向按时刻表排班下，执行班次多、贡献样本 $N_{v}$ 丰富的车辆在梯度更新中被采样的期望频次较高；全车队共享同一套网络参数使得执行高峰加班次、样本量 $N_{v}$ 较少的车辆能够直接复用主力车辆学到的公共状态—动作映射特征，同时配合第3.2.3节的类别特征嵌入保留车辆与班次的个体差异。不同于依据时序差分误差调整抽样权重的优先经验回放机制（Prioritized Experience Replay）[209]，本章采用上述均匀共享回放方式，使回放样本分布自然反映车队各班次的真实事件频率，从而重点考察类别表征与价值正则化机制本身的作用。

[P0951] 3.2.3 状态表示与类别特征嵌入

[P0952] 如第3.1节所述，全车队共享同一策略与价值网络的前提，是状态表示必须兼具“公共运行规律共享”与“异质服务背景区分”双重能力：若仅输入前后车头时距等连续观测量，确定性策略对相同的前后车头时距只能输出完全相同的驻站时长；然而在真实公交运营中，同样的前向偏小车头时距若出现在早高峰客流密集的商圈大站，与出现在平峰客流稀少的末端站点，其下游潜在候车增量及驻站对后续班次周转的影响截然不同。与此同时，车辆编号、站点序号、运行方向和运营时段本质上属于离散的类别变量（Categorical Variables）——车辆编号与方向编码不具备连续数值的大小或距离度量意义，而沿线各站点的客流吸引强度、换乘衔接属性与通行阻抗亦不随站点序号呈单调线性变化，直接将类别整数编号作为连续实数输入神经网络会强加错误的数值偏序归纳偏置。

[P0953 M000573,M000574,M000575,M000576,M000577,M000578,M000579,M000580,M000581,M000582,M000583,M000584] 为在共享网络参数的同时恰当表征离散类别信息，本章借鉴实体嵌入（Entity Embedding）[88]与多任务表征学习[89]思想，为每一类离散身份或背景特征构建可学习的低维稠密嵌入矩阵[87]。一般地，设状态中包含 $m$ 个离散类别变量 $c_{1},c_{2},\ldots,c_{m}$ 以及连续运行观测向量 $\mathbf{o}$，第 $j$ 个类别变量共有 $n_{j}$ 个可能的离散取值，为其分配可训练的嵌入查找矩阵 $E_{j} \in \mathbb{R}^{n_{j} \times d_{j}}$（矩阵的第 $c_{j}$ 行向量 $E_{j}(c_{j}) \in \mathbb{R}^{d_{j}}$ 即对应类别取值 $c_{j}$ 的嵌入表征），并将各类别嵌入向量与连续观测向量 $\mathbf{o}$ 拼接（记为 $\oplus$），形成策略网络或价值网络的基础输入向量 $\mathbf{x}$：

[P0955 式(3-4) M000585] $\mathbf{x} = \left\lbrack \, E_{1}(c_{1}) \oplus E_{2}(c_{2}) \oplus \cdots \oplus E_{m}(c_{m}) \oplus \mathbf{o}\, \right\rbrack$

[P0956 式(3-4)] (3-4)

[P0957 M000586,M000587,M000588] 对于基数为 $n_{j}$ 的第 $j$ 个类别变量，其嵌入空间维数 $d_{j}$ 按如下经验准则确定：

[P0959 式(3-5) M000589] $d_{j} = min\left( 50,\ \lfloor n_{j}/2\rfloor \right)$

[P0960 式(3-5)] (3-5)

[P0961 M000590,M000591,M000592,M000593] 在本章双向单线路场景中，离散类别变量取车辆编号 $c_{v}$、站点位置序号 $c_{s}$、运营时段 $c_{t}$ 与运行方向 $c_{d}$ 四项（多线路场景进一步增加线路与运行方向编码，见表2-4），按式(3-4)与式(3-5)构造的共享网络完整输入表征为：

[P0963 式(3-6) M000594] $\mathbf{x} = \left\lbrack \,{Emb}_{v}(c_{v}) \oplus {Emb}_{s}(c_{s}) \oplus {Emb}_{t}(c_{t}) \oplus {Emb}_{d}(c_{d}) \oplus \mathbf{o}\, \right\rbrack$

[P0964 式(3-6)] (3-6)

[P0965] 式中，策略网络与各动作价值网络分别维护各自独立的嵌入矩阵参数，并在训练过程中随策略梯度损失或价值回归损失通过反向传播端到端同步更新。

[P0966 M000595,M000596,M000597,M000598,M000599,M000600,M000601,M000602,M000603,M000604] 从网络参数结构审视，可学习类别嵌入与传统独热编码（One-Hot Encoding）改变了类别信息进入第一层隐藏层的代数映射方式。设某类别变量具有 $n$ 个离散取值，第一层全连接隐藏层宽度为 $h$：若采用独热编码直接拼接输入，该类别变量在第一层对应的权重矩阵规模为 $n \times h$，参数量为 $n \cdot h$；若采用 $d$ 维可学习嵌入，该类别变量相当于将线性映射分解为 $n \times d$ 的嵌入矩阵与 $d \times h$ 的第一层投影矩阵之积，参数量为 $d(n + h)$ 且映射矩阵的秩受限于 $rank \leq d$。当类别基数 $n$ 较小时，嵌入分解未必减少总参数量，但其低秩瓶颈结构能够引导网络将运行特性相似的站点、车辆或时段自动聚类至邻近的嵌入流形区域；相反，独热编码将所有类别置于两两正交的稀疏高维顶点上，增加了首层输入宽度与优化难度。为严格分离“保留类别信息本身”与“采用可学习嵌入编码方式”各自的贡献，本章在第3.4.5节专门设计了参数量完全对齐的“屏蔽类别嵌入对照（将嵌入向量置零）”与“独热编码对照”实验。

[P0967] 3.2.4 优化目标与奖励函数构造

[P0968] 为全面检验驻站策略在不同运营导向下的控制行为，本章分别以面向车头时距规律性的计划间隔奖励与面向乘客服务水平的乘客时间奖励独立训练策略，并在评价阶段同步统计两类物理指标。

[P0969 M000605,M000606,M000607,M000608,M000609,M000610] 在双向单线路场景中，所有班次共享相同的计划发车间隔 $h_{s} = 360$ 秒。如第2.7.4节所述，仅评价前后车头时距是否对称相等（$|h_{f} - h_{b}|$）无法识别前后两车同时严重晚点或车头时距同时偏密的情形；因此，定义单侧车头时距 $h$ 相对于计划间隔 $h_{s}$ 的偏差得分 $\varphi(h)$ 以及自适应前向偏差权重 $\omega(h_{f},h_{b})$ 如下：

[P0971 式(3-7) M000611] $\varphi(h) = - |\, h - h_{s}\,|,\quad\quad\omega(h_{f},h_{b}) = \frac{|h_{f} - h_{s}|}{|h_{f} - h_{s}| + |h_{b} - h_{s}| + \epsilon}$

[P0972 式(3-7)] (3-7)

[P0973 M000612,M000613,M000614] 式中，$\epsilon > 0$ 为避免分母为零的极小正数（取 $10^{- 6}$）。结合前、后向计划偏差加权项、前后车头时距不均衡惩罚项以及前向或后向偏差超过计划间隔一半（$180$ 秒）时触发的阶跃大偏差惩罚项，双向单线路的计划间隔奖励函数构造为：

[P0975 式(3-8) M000615] $R(h_{f},h_{b})$

[P0976 式(3-8) M000616] $= \omega(h_{f},h_{b})\,\varphi(h_{f}) +$

[P0977 式(3-8) M000617] $\left( 1 - \omega(h_{f},h_{b}) \right)\,\varphi(h_{b}) - 0.5\,|\, h_{f} - h_{b}\,| - 20\,\mathbb{I}\left( |\, h_{f} - h_{s}\,| > 180\ \text{或}\ |\, h_{b} - h_{s}\,| > 180 \right)$

[P0978 式(3-8)] (3-8)

[P0979 M000618,M000619] 在式(3-8)中，当本车前后相邻车辆均在途可观测时，同步评价前、后向偏差，且只要前向或后向偏离计划超过 $180$ 秒即一次性扣除 $20$ 分惩罚；当处于服务首末边界、仅有前车或仅有后车的车头时距可观测时，奖励退化为可观测方向的绝对计划偏差及对应的大偏差惩罚，无邻车方向不计惩罚。

[P0980 M000620,M000621,M000622,M000623,M000624,M000625,M000626] 在长沙多线路场景中，不同线路及不同时段的相邻班次具有非均匀的计划发车间隔。记当前决策车辆与前、后相邻同线班次对应的计划间隔分别为 $h_{f}^{*},h_{b}^{*}$，前、后邻车存在示性标记分别为 $I_{f},I_{b} \in \{ 0,1\}$。前车与后车均存在（$I_{f} = I_{b} = 1$）时，定义前向与后向计划绝对偏差 $e_{f},e_{b}$、自适应前向权重 $\omega_{h}$、前后计划间隔比值 $R_{h}$ 及基础间隔奖励项 $r_{base}$ 为：

[P0982 式(3-9) M000627] $e_{f} = |\, h_{f} - h_{f}^{*}\,|,\quad e_{b} = |\, h_{b} - h_{b}^{*}\,|,\quad$

[P0983 式(3-9) M000628] $\omega_{h} = \frac{e_{f}}{e_{f} + e_{b} + 10^{- 6}},\quad R_{h} = \frac{h_{f}^{*}}{\max\left( h_{b}^{*},\ 10^{- 6} \right)},\quad$

[P0984 式(3-9) M000629] $r_{base} = - \omega_{h}\, e_{f} - (1 - \omega_{h})\, e_{b} - \frac{|\, h_{f} - R_{h}\, h_{b}\,|}{1 + R_{h}}$

[P0985 式(3-9)] (3-9)

[P0986 M000630,M000631,M000632,M000633] 同时，采用平滑双曲正切函数构造前、后向相对于各自半计划间隔阈值（$0.5\, h_{f}^{*}$ 与 $0.5\, h_{b}^{*}$）的大偏差惩罚项 $p_{f},p_{b}$，得到多线路计划间隔奖励 $r^{sched}$：

[P0988 式(3-10) M000634] $p_{f} = 20\, I_{f}\,\tanh\left( \frac{e_{f} - 0.5\, h_{f}^{*}}{30} \right),\quad$

[P0989 式(3-10) M000635] $\quad p_{b} = 20\, I_{b}\,\tanh\left( \frac{e_{b} - 0.5\, h_{b}^{*}}{30} \right),\quad\quad$

[P0990 式(3-10) M000636] $r^{sched} = r_{base} - max\left( 0,\ p_{f} + p_{b} \right)$

[P0991 式(3-10)] (3-10)

[P0992 M000637,M000638,M000639,M000640,M000641] 当仅存在前车或后车单一邻车时，$r_{base}$ 取存在的前车或后车对应的计划绝对偏差的负值（$- e_{f}$ 或 $- e_{b}$），无邻车方向的大偏差项置零；容易验证，当令 $h_{f}^{*} = h_{b}^{*} = h_{s} = 360\text{ s}$（即 $R_{h} = 1$）并将双曲正切平滑过渡替换为阶跃示性函数时，除前后向偏差同时越限情形外，式(3-9)～(3-10)即退化为单线路式(3-8)。

[P1000 式(3-12)] (3-12)

[P1001 M000651,M000652,M000653,M000654,M000655,M000656,M000657] 其呈明显的单峰脊形结构，仅在计划间隔 $h = h_{s} = 360\text{ s}$ 处取得唯一全局最大值，能够有效阻止前后车辆维持等间隔但整体偏离运行计划的漂移现象。第二，在固定平均时距而改变前后时距差 $\delta_{h} = h_{f} - h_{b}$ 的截面上，指数项的斜率绝对值为 $\tau_{h}^{- 1}exp( - |\delta_{h}|/\tau_{h})$；当衰减尺度 $\tau_{h}$ 较小时（如取 $\tau_{h} = 1\text{ s}$），一旦 $|\delta_{h}|$ 较大（严重失衡），指数项及梯度迅速衰减趋近于零（饱和死区），导致策略在最需要大力纠偏的严重失衡状态下反而丧失了改进时距的梯度信号，转而受式(3-11)第二项动作抑制项 $exp( - a/60)$ 主导而放弃驻站；相比之下，本文计划间隔奖励的绝对偏差项在全定义域内保持恒定的非零线性斜率，越过阈值后进一步叠加惩罚，从而在严重失衡区域始终提供指向计划间隔的恢复梯度。

[P1005] 3.2.5 共享策略与鲁棒价值模型（RE-SAC）

[P1006 M000660,M000661,M000662,M000663,M000664,M000665,M000666,M000667] 本章构建的车队共享驻站控制模型由一个参数化共享策略网络 $\pi_{\theta}(a \mid s)$ 与 $K$ 个独立初始化的动作价值网络 $\{ Q_{\phi_{k}}(s,a)\}_{k = 1}^{K}$（及其对应的慢速更新目标网络 $\{{\widehat{Q}}_{\phi_{k}'}(s,a)\}_{k = 1}^{K}$）组成。对于任意给定策略 $\pi$，沿同一车辆的有效决策事件序列 $i$，纯环境奖励下的动作价值函数 $Q^{\pi}(s_{i},a_{i})$ 与状态价值函数 $V^{\pi}(s_{i})$ 满足：

[P1008 式(3-13) M000668] $Q^{\pi}\left( s_{i},\ a_{i} \right) = \mathbb{E}_{\pi}\left\lbrack \,\sum_{j \geq i}^{}\gamma^{\, j - i}\, r_{j}\mspace{6mu} \middle| \mspace{6mu} s_{i},\ a_{i} \right\rbrack,\quad\quad$

[P1009 式(3-13) M000669] $V^{\pi}(s) = \mathbb{E}_{a \sim \pi( \cdot \mid s)}\left\lbrack \, Q^{\pi}(s,\ a)\, \right\rbrack$

[P1010 式(3-13)] (3-13)

[P1011 M000670] 在SAC最大熵强化学习框架下，长期价值评估进一步纳入策略分布的信息熵，相应的软状态价值 $V_{soft}^{\pi}(s)$ 由软动作价值与动作对数概率共同构成：

[P1013 式(3-14) M000671] $V_{soft}^{\pi}(s) = \mathbb{E}_{a \sim \pi( \cdot \mid s)}\left\lbrack \, Q_{soft}^{\pi}(s,\ a) - \alpha\log\pi(a \mid s)\, \right\rbrack$

[P1014 式(3-14)] (3-14)

[P1015 M000672,M000673,M000674,M000675,M000676] 式中，$\alpha > 0$ 为熵温度系数，状态价值直接由策略网络对动作价值网络的期望给出，不另行训练独立的状态价值网络。针对包含 $K > 1$ 个价值网络的集成评价器，定义当前在线价值网络集成在状态—动作对 $(s,a)$ 上的预测均值 $\bar{Q}(s,a)$ 与样本标准差 $\sigma_{Q}(s,a)$ 分别为：

[P1017 式(3-15) M000677] $\bar{Q}(s,\ a) = \frac{1}{K}\sum_{k = 1}^{K}Q_{\phi_{k}}(s,\ a),\quad\quad$

[P1018 式(3-15) M000678] $\sigma_{Q}(s,\ a) = \left\lbrack \,\frac{1}{K - 1}\sum_{k = 1}^{K}(\, Q_{\phi_{k}}(s,\ a) - \bar{Q}(s,\ a)\,)^{2}\, \right\rbrack^{1/2}$

[P1019 式(3-15)] (3-15)

[P1020] 在此集成结构之上，针对第3.1节剖析的两类价值估计失效根源，RE-SAC引入两类具有明确物理与统计分工的正则化机制[119]：

[P1021 M000679,M000680,M000681,M000682] 针对环境固有偶然随机扰动的目标网络权重范数正则化项。在数据充足但单次运行回报受随机客流和路况剧烈扰动的区域，需要从结构上限制后继状态价值函数对输入状态扰动的敏感度，以稳定时序差分自举目标。根据第2.3节式(2-20)的鲁棒—正则对偶理论，固定状态动作对 $(s,a)$，当允许的后继状态分布集合 $\mathcal{P}_{s,a}$ 由围绕名义分布 $p^{\circ}$、半径为 $\rho_{ipm}$ 的一阶Wasserstein距离（或Kantorovich积分概率度量）球给出时，由Kantorovich-Rubinstein对偶定理，最不利分布下的后继状态期望价值下界满足[206,118]：

[P1023 式(3-16) M000683] $\inf_{q \in \mathcal{P}_{s,a}}\mathbb{E}_{s' \sim q}\left\lbrack \, V(s')\, \right\rbrack\mspace{6mu} \geq \mspace{6mu}\mathbb{E}_{s' \sim p^{\circ}}\left\lbrack \, V(s')\, \right\rbrack\mspace{6mu} - \mspace{6mu}\rho_{ipm} \cdot Lip(V)$

[P1024 式(3-16)] (3-16)

[P1025 M000684,M000685,M000686,M000687,M000688,M000689,M000690,M000691] 式中，$Lip(V)$ 为后继状态价值函数 $V$ 关于状态空间度量的Lipschitz常数（详细推导及与CVaR尾部风险重加权的联系见附录A.7）[109]。由于前馈深度神经网络的全局Lipschitz常数受控于各隐藏层权重矩阵的算子范数，RE-SAC在工程实现上提取第 $k$ 个目标价值网络各层权重矩阵的逐元素 $\mathcal{l}_{1}$ 范数之和 $\kappa_{k}$ 作为 $Lip(V)$ 的可计算代理，并以系数 $\lambda_{ale} \geq 0$ 从第 $k$ 个成员的自举价值回归目标中扣除。该修正通过惩罚过大的目标网络权重范数，抑制自举价值目标对环境随机噪声的过度敏感，且相比于每次更新时在线求解内层极小化问题几乎不增加任何额外计算开销。

[P1026 M000692,M000693,M000694,M000695,M000696,M000697,M000698,M000699] 针对有限样本认知不确定性的价值集成分歧惩罚机制。由于独立初始化的 $K$ 个价值网络在训练样本密集的已知区域预测趋于一致，而在训练样本稀疏或未覆盖的OOD区域预测分歧显著增大，成员间的估计分歧自然构成了认知不确定性的有效度量。RE-SAC在三个具体损失位置协同施加集成分歧惩罚：其一，在自举价值回归目标中，计算目标价值网络集成在后继状态动作 $(s',a')$ 上的样本方差 $\Gamma_{epi}(s',a')$，以系数 $\lambda_{epi} \geq 0$ 从自举目标中扣除（见式(3-27)与式(3-29)），防止后继状态上的高估误差逆向传播；其二，在当前价值网络回归损失中，加入系数为 $\beta_{ood} \geq 0$ 的当前在线集成标准差惩罚项 $\beta_{ood}\,\sigma_{Q}(s,a)$（见式(3-31)），约束各价值网络成员在数据分布边缘的过度发散；其三，在策略网络优化损失中，按均值加负向标准差的下置信界（LCB）准则 $\bar{Q}(s,a) + \beta_{lcb}\,\sigma_{Q}(s,a)$（其中 $\beta_{lcb} \leq 0$，见式(3-32)）评价候选驻站动作，使策略在平均价值相近时主动规避缺乏一致评价的高分歧动作。

[P1027 M000700,M000701,M000702,M000703] 此外，与标准SAC取双目标网络最小值构造全员共享的单一目标[63]、TD3的截断双Q[62]以及REDQ的随机子集最小化[112]不同，RE-SAC在构造自举目标时令第 $k$ 个在线价值网络 $Q_{\phi_{k}}$ 仅向其自身对应的第 $k$ 个目标价值网络 ${\widehat{Q}}_{\phi_{k}'}$ 回归，而非强制所有成员回归至同一个集成最小值目标；这一独立自举结构有效避免了集成成员在训练过程中快速同质化坍缩，为集成分歧持续提供有效的认知不确定性信号奠定了结构基础。

[P1028] 3.2.6 局部车头时距与乘客成本解析分析

[P1029] 在进入强化学习求解之前，本节从解析角度回答两个基本交通工程问题：其一，减小车头时距的波动方差在何种条件下能够降低乘客平均候车时间？其二，单次附加驻站在何种局部条件下能够真正降低乘客广义时间成本？这两项解析结论为理解“为何车头时距均衡不必然等同于乘客时间成本下降”提供了坚实的机理依据。

[P1030 M000704,M000705,M000706,M000707,M000708,M000709,M000710,M000711,M000712,M000713] 首先考察车头时距均值与方差对乘客候车时间的作用。设高频公交服务在某站点的随机车头时距为正随机变量 $H > 0$，其一阶矩 $\mathbb{E\lbrack}H\rbrack$ 与二阶矩 $\mathbb{E\lbrack}H^{2}\rbrack$ 均有限，变异系数定义为 ${CV}_{H} = \sqrt{Var(H)}\mathbb{/E\lbrack}H\rbrack$。假设乘客到达过程与车辆运行过程相互独立、乘客在每个车头时距区间内均匀随机到达，且车辆额定容量充足、站台无跨班次滞留队列。当某次实际车头时距实现值为 $h$ 时，落入该间隔内的乘客平均候车时间为 $h/2$；而随机抽取一名到达乘客，其恰好落入长度为 $h$ 的间隔内的概率与间隔长度 $h$ 成正比（即检验悖论的长度偏倚采样，$f_{len}(h) = hf_{H}(h\mathbb{)/E\lbrack}H\rbrack$）。据此对间隔长度积分加权，可得随机到达乘客的平均候车时间期望值 $\mathbb{E\lbrack}W\rbrack$ 为：

[P1032 式(3-17) M000714] $\mathbb{E\lbrack}W\rbrack\mspace{6mu} = \mspace{6mu}\frac{\mathbb{E\lbrack}H^{2}\rbrack}{2\,\mathbb{E\lbrack}H\rbrack}\mspace{6mu} = \mspace{6mu}\frac{\mathbb{E\lbrack}H\rbrack}{2} + \frac{Var(H)}{2\,\mathbb{E\lbrack}H\rbrack}\mspace{6mu} = \mspace{6mu}\frac{\mathbb{E\lbrack}H\rbrack}{2}\left( 1 + {CV}_{H}^{2} \right)$

[P1033 式(3-17)] (3-17)

[P1034 M000715,M000716,M000717] 式(3-17)表明，在平均发车间隔 $\mathbb{E\lbrack}H\rbrack$ 保持不变、容量充足且无滞留的理想前提下，通过驻站控制减小车头时距方差 $Var(H)$ 确实能够直接降低乘客平均候车时间。然而，若过度驻站拖慢了全线周转速度进而推高了平均间隔 $\mathbb{E\lbrack}H\rbrack$，或者在高需求场景下车辆已达容量上限产生跨班次滞留候车队列，仅减小局部间隔波动便不再保证平均候车时间下降；并且，式(3-17)完全未计入附加驻站给车内已载乘客带来的额外等待代价。

[P1035 M000718,M000719,M000720,M000721] 为此，进一步分析单次附加驻站对局部前后车头时距与局部乘客广义时间成本的作用。在局部近似分析中，暂时固定当前控制站点处前车与后车的参考到站时刻，并假设后车不在本车附加驻站期间发生超车。记本车未施加附加驻站时的前、后向车头时距分别为 $h_{f}$ 与 $h_{b}$，允许的最大驻站上界为 $\bar{a} = min(a_{\max},h_{b})$；当本车施加 $a \in \lbrack 0,\bar{a}\rbrack$ 秒的附加驻站后，调整后的前、后向车头时距分别为：

[P1037 式(3-18) M000722] $h_{f}(a) = h_{f} + a,\quad\quad h_{b}(a) = h_{b} - a,\quad\quad a \in \left\lbrack 0,\ min(a_{\max},\ h_{b}) \right\rbrack$

[P1038 式(3-18)] (3-18)

[P1039] 将式(3-18)两式相加与相减，立即得到：

[P1041 式(3-19) M000723] $h_{f}(a) + h_{b}(a) = h_{f} + h_{b},\quad\quad h_{f}(a) - h_{b}(a) = h_{f} - h_{b} + 2a$

[P1042 式(3-19)] (3-19)

[P1043 M000724,M000725,M000726,M000727,M000728,M000729] 式(3-19)表明，单次驻站保持前后车头时距之和 $h_{f} + h_{b}$ 恒定不变——这从数学上印证了驻站控制只是在既有相邻车辆之间重新分配服务时间间隔，并不会创造新的运力供给。若仅以最小化前、后向车头时距相对于共同计划间隔 $h_{s}$ 的局部平方偏差之和 $L_{hw}(a) = (h_{f} + a - h_{s})^{2} + (h_{b} - a - h_{s})^{2}$ 为目标，由于 $d^{2}L_{hw}/da^{2} = 4 > 0$，求导并投影至可行域 $\lbrack 0,\bar{a}\rbrack$ 可得局部车头时距均衡最优驻站时长 $a_{bal}^{*}$（该式同时构成第3.4.2节无需训练的“车头时距均衡规则”基线）：

[P1045 式(3-20) M000730] $a_{bal}^{*} = \Pi_{\lbrack 0,\,\bar{a}\rbrack}\left( \frac{h_{b} - h_{f}}{2} \right)$

[P1046 式(3-20)] (3-20)

[P1047 M000731,M000732,M000733,M000734,M000735,M000736,M000737,M000738,M000739] 式中，$\Pi_{\lbrack 0,\bar{a}\rbrack}( \cdot ) = min\{\bar{a},max(0, \cdot )\}$ 表示区间截断算子。例如，当 $h_{f} = 180\text{ s},h_{b} = 540\text{ s}$ 时，完全恢复对称均衡需驻站 $180\text{ s}$，受 $a_{\max} = 60\text{ s}$ 约束单次最多调整为 $240\text{ s}$ 与 $480\text{ s}$；而当 $h_{f} = h_{b} = 600\text{ s}$ 时，前后间隔虽已对称（$a_{bal}^{*} = 0$），却双双严重超出计划间隔 $360\text{ s}$，继续驻站只会破坏对称而无法弥补发车频率不足。

[P1048 M000740,M000741,M000742,M000743,M000744] 现在将车内乘客的时间代价纳入上述局部模型。设本站乘客以恒定到达率 $\lambda > 0$（单位：人/秒）均匀到达且车辆容量充足，则前车至本车、本车至后车两个间隔期内到达乘客的期望候车总时间分别为 $\frac{1}{2}\lambda h_{f}^{2}$ 与 $\frac{1}{2}\lambda h_{b}^{2}$。当本车增加 $a$ 秒附加驻站后，本站两个区间候车总时间的净变化量 $\Delta W(a)$ 为：

[P1050 式(3-21) M000745] $\Delta W(a) = \frac{\lambda}{2}\left\lbrack (h_{f} + a)^{2} - h_{f}^{2} \right\rbrack + \frac{\lambda}{2}\left\lbrack (h_{b} - a)^{2} - h_{b}^{2} \right\rbrack = \lambda a^{2} - \lambda a\Delta$

[P1051 式(3-21)] (3-21)

[P1052 M000746,M000747,M000748,M000749,M000750,M000751,M000752] 式中，$\Delta = h_{b} - h_{f}$ 为驻站前的后前向车头时距之差。与此同时，设本车完成必要上下客后车厢内已有 $n$ 名在途乘车乘客，则附加驻站 $a$ 秒将直接使这 $n$ 名乘客增加 $n \cdot a$ 乘客秒的车内等待时间。按照第2.7.4节候车时间权重为2、车内时间权重为1的定义，单次驻站 $a$ 秒引起的局部乘客广义时间总成本净变化量 $\Delta C(a)$ 为：

[P1054 式(3-22) M000753] $\Delta C(a) = 2\,\Delta W(a) + n \cdot a = 2\lambda a^{2} - (2\lambda\Delta - n)a$

[P1055 式(3-22)] (3-22)

[P1056 M000754,M000755,M000756,M000757,M000758,M000759,M000760] 由于 $\lambda > 0$ 时 $\Delta C(a)$ 为关于 $a$ 的严格凸二次函数（二阶导数为 $4\lambda > 0$），令一阶导数 $\Delta C'(a) = 4\lambda a - 2\lambda\Delta + n = 0$ 并截断至可行区间 $\lbrack 0,\bar{a}\rbrack$，可得局部乘客广义时间成本最小化的最优驻站时长 $a_{pass}^{*}$：

[P1058 式(3-23) M000761] $a_{pass}^{*} = \Pi_{\lbrack 0,\,\bar{a}\rbrack}\left( \frac{\Delta}{2} - \frac{n}{4\lambda} \right)$

[P1059 式(3-23)] (3-23)

[P1060 M000762,M000763,M000764] 进一步令式(3-22)满足 $\Delta C(a) = 2\lambda a\,(a - a_{c}) < 0$，可解得单次非零驻站（$a > 0$）能够真正降低局部乘客广义时间总成本的临界驻站时长上界 $a_{c}$：

[P1062 式(3-24) M000765] $a_{c} = \Delta - \frac{n}{2\lambda},\quad\quad\Delta C(a) < 0 \Leftrightarrow 0 < a < \Delta - \frac{n}{2\lambda}$

[P1063 式(3-24)] (3-24)

[P1064] 对比式(3-20)、式(3-23)与式(3-24)可以得出三条重要的交通控制推论：

[P1065 M000766,M000767,M000768,M000769,M000770] 与单纯追求车头时距对称均衡的解 $a_{bal}^{*} = \Delta/2$ 相比，以乘客广义时间成本最小化为目标的最优驻站时长 $a_{pass}^{*}$ 必须额外扣除惩罚项 $\frac{n}{4\lambda}$：车内已载乘客人数 $n$ 越多、或本站候车到达率 $\lambda$ 越低，最优驻站时长越短；

[P1066 M000771,M000772,M000773,M000774,M000775] 仅当时距差满足 $\Delta = h_{b} - h_{f} > \frac{n}{2\lambda}$ 时，临界值 $a_{c} > 0$，才存在能够产生净乘客时间收益的正向驻站空间；若 $\Delta \leq \frac{n}{2\lambda}$，任何非零附加驻站所造成的车内时间损失均大于候车时间节省（$\Delta C(a) > 0$），此时最优决策是不驻站（$a_{pass}^{*} = 0$）；

[P1067 M000776,M000777,M000778,M000779,M000780,M000781] 当 $\frac{n}{2\lambda} < \Delta < \frac{n}{\lambda}$ 时，存在一个危险的“目标背离区间” $a \in \left( a_{c},\ \frac{\Delta}{2} \right\rbrack$：在此区间内选择驻站时长（例如直接执行完全时距均衡规则 $a = \Delta/2$），虽然确实缩小了前后车头时距不均衡度（$|h_{f}(a) - h_{b}(a)| = \Delta - 2a < \Delta$），但由于驻站时长越过了成本平衡临界点 $a_{c}$，局部乘客广义时间总成本反而净增加（$\Delta C(a) > 0$）。

[P1068] 上述解析推导清晰地解释了为何在车内载客量较高或后续供给受限时，单纯优化车头时距均衡度的控制律往往伴随乘客总出行时间的上升，从而为第3.4节同时开展两类优化目标实验并双向核验物理指标提供了理论判据。

[P1069] 3.3 求解方法

[P1070] 本节给出鲁棒集成软演员评论家算法（RE-SAC）[119]的完整求解流程与理论性质分析。已有深度强化学习研究曾从解耦动作选择与评价（Double DQN[210]）、分离状态价值与优势（Dueling DQN[211]）以及多机制组合（Rainbow[212]）等角度抑制估计偏差；但由于神经网络函数逼近、自举更新与异策略回放共同引发的不稳定耦合（即强化学习中的“死亡三角”问题）[213]客观存在，本章先建立RE-SAC的价值评价与策略优化损失函数，再在正则化马尔可夫决策过程框架[117]下证明固定惩罚算子的压缩映射性质及动作价值误差分解定理。

[P1071] 3.3.1 鲁棒集成价值评价

[P1072 M000782] 在最大熵强化学习框架[63,205]下，车队共享驻站策略 $\pi_{\theta}$ 的优化目标是最大化期望折扣奖励与策略微分熵的加权和：

[P1074 式(3-25) M000783] $J(\pi_{\theta}) = \mathbb{E}_{\pi_{\theta}}\left\lbrack \,\sum_{i = 0}^{\infty}\gamma^{\, i}(\, r_{i} + \alpha\,\mathcal{H(}\pi_{\theta}( \cdot \mid s_{i}))\,)\, \right\rbrack$

[P1075 式(3-25)] (3-25)

[P1076 M000784,M000785,M000786] 对于固定状态 $s$ 与给定动作价值函数 $Q(s, \cdot )$，在满足概率归一化的密度空间中最大化内层目标 $\mathbb{E}_{a \sim \pi( \cdot \mid s)}\lbrack Q(s,a)\rbrack + \alpha\,\mathcal{H(}\pi( \cdot \mid s))$，由拉格朗日乘子法可得最优玻尔兹曼（Boltzmann）策略分布密度为：

[P1078 式(3-26) M000787] $\pi^{*}(a \mid s) = \frac{\exp\left( Q(s,\ a)/\alpha \right)}{\int_{\mathcal{A}}^{}\exp\left( Q(s,\ a')/\alpha \right)\, da'}$

[P1079 式(3-26)] (3-26)

[P1080 M000788,M000789,M000790,M000791,M000792,M000793] 式(3-26)揭示了动作价值估计对策略更新的两条核心作用规律：其一，奖励数值尺度与熵温度 $\alpha$ 共同决定动作选择的尖锐程度——当 $\alpha$ 极小（趋近于0）时，策略分布退化为集中于最大Q值动作的近似狄拉克脉冲分布，极易在训练后期引发边界动作饱和；其二，若在同一状态 $s$ 下对所有候选动作的价值估计同时加上任意仅依赖状态的常数偏移 $c(s)$，分子与分母中的指数因子 $exp(c(s)/\alpha)$ 恰好相互约去，最优动作概率密度 $\pi^{*}(a \mid s)$ 保持完全不变——这一状态共同偏移不变性是第3.3.3节与第3.4.4节剖析价值误差机理的基石。

[P1081 M000794,M000795,M000796,M000797,M000798,M000799,M000800] 为在自举更新中同时抑制偶然随机扰动与认知高估偏差，RE-SAC维护 $K$ 个动作价值网络 $\{ Q_{\phi_{k}}\}_{k = 1}^{K}$ 及其对应的目标价值网络 $\{{\widehat{Q}}_{\phi_{k}'}\}_{k = 1}^{K}$。当前在线价值网络集成的预测均值 $\bar{Q}(s,a)$ 与样本标准差 $\sigma_{Q}(s,a)$ 已由式(3-15)给出；对于目标价值网络集成，定义其在状态动作对 $(s,a)$ 上的预测样本方差 $\Gamma_{epi}(s,a)$ 为：

[P1089 M000809,M000810,M000811,M000812,M000813,M000814] 从共享经验回放池 $\mathcal{D}$ 中采样转移数据 $(s,a,r,s',d)$，并利用当前策略网络在后继状态采样动作 $a' \sim \pi_{\theta}( \cdot \mid s')$，RE-SAC为第 $k$ 个价值网络 $Q_{\phi_{k}}$ 独立构造包含两类不确定性修正项的软贝尔曼回归目标 $y_{k}$：

[P1113] 3.3.3 算子收缩性与动作价值误差分解理论分析

[P1114 M000863] 本节从理论上严格证明两项核心结论：第一，在单步更新内目标网络与惩罚项保持冻结的条件下，RE-SAC的正则化贝尔曼更新算子保持严格的 $\gamma$-压缩映射性质与唯一不动点；第二，动作价值网络的数值拟合误差可正交分解为“状态共同偏移”与“动作相关相对误差”，且驻站动作选择的次优性上界仅取决于后者。

[P1115 M000864,M000865,M000866,M000867] 首先考察正则化MDP框架[117]下的贝尔曼更新算子。在有限状态动作空间 $\mathcal{S \times A}$ 中，记单次价值更新内由冻结目标网络给出的合成保守惩罚项为非负有界函数 $\Lambda(s,a) = \mathbb{E}_{s' \sim P( \cdot \mid s,a),\, a' \sim \pi( \cdot \mid s')}\left\lbrack \lambda_{epi}\,\Gamma_{epi}(s',a') + \lambda_{ale}\,\kappa_{k} \right\rbrack$，定义作用在有界动作价值函数空间 $\mathcal{B(S \times A)}$ 上的正则化贝尔曼算子 $\mathcal{T}_{\Lambda}$ 为：

[P1117 式(3-33) M000868] $(\mathcal{T}_{\Lambda}Q)(s,\ a) = R(s,\ a) + \gamma\,\left( \,\mathbb{E}_{s' \sim P( \cdot \mid s,a)}\left\lbrack \, V^{Q}(s')\, \right\rbrack - \Lambda(s,\ a)\, \right)$

[P1118 式(3-33)] (3-33)

[P1119 M000869,M000870,M000871,M000872,M000873,M000874] 式中，后继状态价值聚合算子 $V^{Q}(s')$ 可取最优最大值聚合 $V^{Q}(s') = \max_{a'\mathcal{\in A}}Q(s',a')$、固定正温度 $\alpha > 0$ 下的软最大值（Log-Sum-Exp）聚合 $V^{Q}(s') = \alpha\log\sum_{a'}^{}\exp(Q(s',a')/\alpha)$，或固定策略 $\pi$ 下的软期望聚合 $V^{Q}(s') = \mathbb{E}_{a' \sim \pi( \cdot \mid s')}\lbrack Q(s',a') - \alpha\log\pi(a' \mid s')\rbrack$。

[P1120 M000875,M000876,M000877,M000878,M000879,M000880] 命题3.1（冻结惩罚下正则化贝尔曼算子的收缩性）：设状态转移核 $P( \cdot \mid s,a)$ 满足非负性与概率归一性，折扣因子 $\gamma \in \lbrack 0,1)$，且在单次价值迭代步内合成惩罚项 $\Lambda(s,a)$ 由冻结的目标网络给出（即不随被更新的当前输入价值函数 $Q$ 变化），则对任意有界动作价值函数 $Q_{1},Q_{2}\mathcal{\in B(S \times A)}$，算子 $\mathcal{T}_{\Lambda}$ 在无穷范数下满足严格收缩性质：

[P1122 式(3-34) M000881] $\parallel \,\mathcal{T}_{\Lambda}Q_{1} - \mathcal{T}_{\Lambda}Q_{2}\, \parallel_{\infty}\mspace{6mu} \leq \mspace{6mu}\gamma\, \parallel \, Q_{1} - Q_{2}\, \parallel_{\infty}$

[P1123 式(3-34)] (3-34)

[P1124 M000882,M000883,M000884,M000885,M000886,M000887,M000888,M000889,M000890,M000891,M000892,M000893,M000894,M000895,M000896,M000897] 证明：可通过检验Blackwell充分条件（单调性与常值平移折扣性）或直接作差予以证明。令 $\delta_{Q} = \parallel Q_{1} - Q_{2} \parallel_{\infty}$，则对任意 $(s',a')$ 逐点有 $Q_{2}(s',a') - \delta_{Q} \leq Q_{1}(s',a') \leq Q_{2}(s',a') + \delta_{Q}$。上述三种后继价值聚合算子 $V^{Q}(s')$ 均同时满足单调性（若 $Q_{1} \leq Q_{2}$ 则 $V^{Q_{1}} \leq V^{Q_{2}}$）与常值平移不变性（对任意常数 $c\mathbb{\in R}$，$V^{Q + c}(s') = V^{Q}(s') + c$），故对任意后继状态 $s'$ 均有 $|V^{Q_{1}}(s') - V^{Q_{2}}(s')| \leq \delta_{Q}$。比较同一状态动作对 $(s,a)$ 在算子 $\mathcal{T}_{\Lambda}$ 作用下的输出之差，由于即时奖励 $R(s,a)$ 与冻结惩罚项 $\Lambda(s,a)$ 与输入 $Q$ 无关，在相减时精确抵消，结合转移核的非负归一性 $\sum_{s'}^{}P(s' \mid s,a) = 1$ 可得：

[P1126 式(3-35) M000898] $\left| \,\left( \mathcal{T}_{\Lambda}Q_{1} \right)(s,\ a) - \left( \mathcal{T}_{\Lambda}Q_{2} \right)(s,\ a)\, \right|\mspace{6mu} \leq$

[P1127 式(3-35) M000899] $\mspace{6mu}\gamma\sum_{s'}^{}P\left( s'\mid s,a \right)\,\left| \, V^{Q_{1}}\left( s' \right) - V^{Q_{2}}\left( s' \right)\, \right|\mspace{6mu} \leq$

[P1128 式(3-35) M000900] $\mspace{6mu}\gamma\,\delta_{Q}\sum_{s'}^{}P(s' \mid s,a)\mspace{6mu} = \mspace{6mu}\gamma\,\left. \parallel\, Q_{1} - Q_{2}\, \right.\parallel_{\infty}$

[P1129 式(3-35)] (3-35)

[P1130 M000901,M000902,M000903] 对所有 $(s,a\mathcal{) \in S \times A}$ 取上确界即证得式(3-34)（对于终止状态转移，后继项乘以 $1 - d = 0$，差值为0，不增大上界）$\blacksquare$。

[P1131 M000904,M000905,M000906,M000907,M000908,M000909,M000910] 由完备度量空间上的巴拿赫不动点定理可知，算子 $\mathcal{T}_{\Lambda}$ 存在唯一的正则化价值不动点 $Q_{\Lambda}^{*}$；若第 $j$ 步更新存在无穷范数不超过 $\varepsilon$ 的函数逼近与采样误差（即 $\parallel Q_{j + 1} - \mathcal{T}_{\Lambda}Q_{j} \parallel_{\infty} \leq \varepsilon$），则由三角不等式递推可得第 $i$ 步价值估计相对于不动点 $Q_{\Lambda}^{*}$ 的误差上界为：

[P1133 式(3-36) M000911] $\parallel \, Q_{i} - Q_{\Lambda}^{*}\, \parallel_{\infty}\mspace{6mu} \leq \mspace{6mu}\gamma^{\, i}\, \parallel \, Q_{0} - Q_{\Lambda}^{*}\, \parallel_{\infty}\mspace{6mu} + \mspace{6mu}\frac{\varepsilon}{1 - \gamma}$

[P1134 式(3-36)] (3-36)

[P1135 M000912,M000913,M000914,M000915,M000916,M000917] 命题3.1、式(3-36)的误差传播界以及惩罚项反例均已在本文附录A中采用交互式定理证明器 Lean 4 完成了机器形式化验证。附录A.6同时给出了惩罚项直接依赖当前在训价值函数 $Q$ 时的扩张反例：若不通过冻结的目标网络计算惩罚、而是令惩罚项随当前 $Q$ 同步线性增长（如单状态算子退化为 $\mathcal{B(}Q) = \gamma Q + \lambda_{ale}Q$），则当有效Lipschitz因子 $\gamma + \lambda_{ale} \geq 1$ 时算子将彻底丧失收缩性并在自举迭代中发散。这从理论上证明了RE-SAC在式(3-29)中采用冻结目标网络计算 $\kappa_{k}$ 与 $\Gamma_{epi}$ 并阻断梯度流，并非单纯的工程实现细节，而是保障自举价值迭代具备收缩稳定性的结构性前提。

[P1136 M000918,M000919,M000920,M000921,M000922,M000923] 落脚到单次驻站决策的候选动作比较，设同一状态 $s$ 下有两个候选驻站时长 $a_{1}$（如短驻站）与 $a_{2}$（如长驻站），策略按式(3-32)的下置信界准则 $q_{c}(s,a) = \bar{Q}(s,a) + \beta_{lcb}\,\sigma_{Q}(s,a)$（$\beta_{lcb} \leq 0$）评估两动作的有效价值差 $D_{eff}(s;a_{1},a_{2})$：

[P1142 M000932,M000933,M000934,M000935,M000936,M000937] 更一般地，为剖析第3.4.4节中“为何降低价值网络的均方回归误差（MSE）并不必然改善驻站控制回报”，可将任意价值估计器 $\widehat{Q}(s,a)$ 相对于真实参考动作价值 $Q^{ref}(s,a)$ 的逐点估计误差 $e_{Q}(s,a) = \widehat{Q}(s,a) - Q^{ref}(s,a)$ 作正交分解。首先，对任意仅依赖于状态 $s$ 而与动作 $a$ 无关的共同估计偏移 $c(s\mathbb{) \in R}$，贪婪动作选择满足平移不变性：

[P1144 式(3-38) M000938] $\underset{a\mathcal{\in A}}{argmax}\mspace{6mu}\left( \, Q^{ref}(s,\ a) + c(s)\, \right)\mspace{6mu} = \mspace{6mu}\underset{a\mathcal{\in A}}{argmax}\mspace{6mu} Q^{ref}(s,\ a)$

[P1145 式(3-38)] (3-38)

[P1146 M000939,M000940,M000941,M000942,M000943,M000944,M000945,M000946] 设同一状态 $s$ 下共有 $M$ 个候选驻站动作 $\{ a_{1},\ldots,a_{M}\}$，第 $i$ 个候选动作上的价值估计误差记为 $e_{Q,i} = \widehat{Q}(s,a_{i}) - Q^{ref}(s,a_{i})$，该状态下的平均估计误差（即状态共同偏移）为 ${\bar{e}}_{Q}(s) = \frac{1}{M}\sum_{i = 1}^{M}e_{Q,i}$。利用恒等式 $\sum_{i = 1}^{M}(e_{Q,i} - {\bar{e}}_{Q}(s)) = 0$，状态 $s$ 上的动作价值均方误差（MSE）可精确正交分解为两项之和：

[P1148 式(3-39) M000947] $\frac{1}{M}\sum_{i = 1}^{M}e_{Q,i}^{2}\mspace{6mu} = \mspace{6mu}({\bar{e}}_{Q}(s))^{2}\mspace{6mu} + \mspace{6mu}\frac{1}{M}\sum_{i = 1}^{M}(e_{Q,i} - {\bar{e}}_{Q}(s))^{2}$

[P1149 式(3-39)] (3-39)

[P1150 M000948,M000949,M000950,M000951,M000952,M000953,M000954,M000955,M000956] 式(3-39)右端第一项 $({\bar{e}}_{Q}(s))^{2}$ 为状态共同偏移平方，它只整体抬高或压低状态 $s$ 下所有动作的数值基线，由式(3-26)与式(3-38)可知其对候选动作的相对排序毫无影响；右端第二项为扣除共同偏移后的动作相关相对误差方差，唯有该项才会扭曲不同驻站时长之间的相对优劣判断。进一步将估计值写为 $\widehat{Q}(s,a) = Q^{ref}(s,a) + c(s) + \eta(s,a)$，其中 $\eta(s,a) = e_{Q}(s,a) - {\bar{e}}_{Q}(s)$ 为动作相关误差，满足一致上界 $\max_{i}|\eta(s,a_{i})| \leq \varepsilon_{act}$。记真实最优候选动作为 $a^{*} = arg\max_{a}Q^{ref}(s,a)$，按估计价值选出的动作为 $\widehat{a} = arg\max_{a}\widehat{Q}(s,a)$，由 $\widehat{Q}(s,\widehat{a}) \geq \widehat{Q}(s,a^{*})$ 消去共同偏移 $c(s)$ 后，立得所选动作的次优价值损失（Regret）上界：

[P1152 式(3-40) M000957] $0\mspace{6mu} \leq \mspace{6mu} Q^{ref}(s,\ a^{*}) - Q^{ref}(s,\ \widehat{a})\mspace{6mu} \leq \mspace{6mu}\eta(s,\ \widehat{a}) - \eta(s,\ a^{*})\mspace{6mu} \leq \mspace{6mu} 2\,\varepsilon_{act}$

[P1153 式(3-40)] (3-40)

[P1154 M000958,M000959] 式(3-39)与式(3-40)从理论上阐明：若某种价值目标修改（如用均值目标替代最小值目标）带来的99%以上MSE下降均来自共同偏移 $({\bar{e}}_{Q}(s))^{2}$ 的减小，而未能压缩动作相关误差 $\varepsilon_{act}$，则其无法改善驻站动作排序与最终控制回报。

[P1155] 3.4 仿真实验与结果分析

[P1156] 为全面检验车队经验共享表征与RE-SAC算法在平稳随机公交环境中的控制效能与作用机理，本节依次从实验设计（3.4.1节）、单线路服务水平对比（3.4.2节）、长期训练稳定性与熵温度干预（3.4.3节）、价值估计误差分解与控制机理诊断（3.4.4节）、组成因素与超参数消融分析（3.4.5节）以及长沙多线路场景验证（3.4.6节）六个层面展开实验研究，并在3.4.7节综合讨论实验结论的成立范围与工程边界。

[P1157] 3.4.1 实验设计与场景输入特征

[P1158] 本章仿真实验首先在双向单线路场景中检验类别特征嵌入车队共享策略与RE-SAC算法对车头时距规律性及乘客出行成本的改善效果，剖析长周期训练中熵温度衰减与动作价值估计误差结构对驻站动作选择的影响机理；进而通过多组受控消融实验，考察类别编码方式、奖励函数结构、在线分歧惩罚位置及价值网络集成规模对控制性能的独立贡献；最后在基于长沙真实运营资料校准的多线路共线走廊场景中，验证RE-SAC相对于标准SAC基线的改进幅度与适用边界。

[P1163] 3.4.2 双向单线路服务水平对比分析

[P1164 M000968,M000969] 为检验类别特征嵌入车队共享机制与RE-SAC算法在双向单线路场景下的整体控制效果，本节依次开展三组递进对比实验：（1）类别嵌入单智能体共享策略（Embedding-SAC）与多智能体基线（参数共享MADDPG、非共享MADDPG）及无附加驻站基线的对比；（2）RE-SAC在不同集成规模 $K$ 及单正则项消融配置下与标准SAC的500回合训练与确定性运行评价对比；（3）无附加驻站基线与第3.2.6节式(3-20)导出的车头时距均衡规则（$a = clip((h_{b} - h_{f})/2,0,60)$）在车头时距指标与乘客候车/车内时间上的对比。

[P1165 M000970,M000971,M000972,M000973,M000974,M000975] 在第一组车队经验共享机制对比中，Embedding-SAC的后期训练累计奖励达到约 $- 430 \times 10^{3}$，显著优于参数共享MADDPG（约 $- 530 \times 10^{3}$）、参数非共享独立MADDPG（约 $- 580 \times 10^{3}$）以及无附加驻站基线（约 $- 980 \times 10^{3}$）[87]。对比参数共享MADDPG与非共享MADDPG可以发现，仅将各车独立网络改为参数共享即可使累计奖励提升约 $50 \times 10^{3}$，证实了在双向时刻表排班下汇集全车队经验的必要性；而Embedding-SAC在此基础上进一步获得约 $100 \times 10^{3}$ 的提升，表明结合车辆、站点、方向与时段类别嵌入的单智能体共享架构能够有效协调全车队的异步驻站决策。考虑到该组前期实验中Embedding-SAC（小批量2048）与MADDPG（小批量128）在算法框架与训练批量上存在差异，类别特征嵌入在完全相同RE-SAC学习器与相同网络规模下的独立贡献将在第3.4.5节中进一步严格剥离检验。

[P1246] 3.4.3 长期训练稳定性与熵温度演化分析

[P1247 M001075,M001076,M001077,M001078,M001079,M001080,M001081,M001082,M001083,M001084,M001085,M001086,M001087,M001088] 观察图3-7的学习曲线可以发现，部分配置在训练中后期（第300至500回合）出现了不同程度的回报回落。为严格检验长期训练中策略性能退化的普遍性，并查明最大熵框架下自动熵温度调节在其中扮演的角色，本节固定500个运行日的训练总长度与每日梯度更新频次（每次完整训练累计执行 $512,000$ 次价值网络更新、$256,000$ 次策略网络更新及 $42$ 次阶段性评价），在三个独立训练随机种子下对比“各价值网络独立构造后继价值目标（式(3-29)）”与“采用截断最小值聚合后继价值目标”两种方案。预先指定训练中前期的第125、150、175和200日作为参考区间，指定训练末期的第425、450、475和500日作为后期区间，先在同一训练重复内平均各评价时点及测试场景，再汇总三次独立训练重复。实验结果显示，两种后继价值目标方案均出现了明显的后期性能退化：相对于参考区间，独立目标组的后期平均回报下降 $12,598$（约为参考回报绝对值的 $2.8\%$），最小值目标组下降 $15,211$（约为参考回报绝对值的 $3.4\%$），且两组的三次独立训练重复无一例外均出现下降。与此同时，追踪内部训练状态发现，在参考区间至后期区间内，自动调节的熵温度系数 $\alpha$ 均值由约 $0.441$ 持续衰减至 $0.095$，而策略输出触及 $0$ 秒或 $60$ 秒端点的边界动作比例则由约 $0.18$ 激增至 $0.40$。

[P1254] 3.4.4 动作价值估计误差与控制机理诊断

[P1255 M001104,M001105] 第3.3.3节在理论上指出，动作价值网络的均方拟合误差（MSE）可正交分解为不改变动作排序的“状态共同偏移 $({\bar{e}}_{Q}(s))^{2}$”与直接决定候选驻站动作相对优劣的“动作相关相对误差方差 $\frac{1}{M}\sum_{i}^{}(e_{Q,i} - {\bar{e}}_{Q}(s))^{2}$”。在深度强化学习中，一个常见的直觉误区是盲目追求动作价值网络在全状态—动作空间上绝对数值拟合精度（即降低 MSE）的提升。然而对于双向逐站驻站控制而言，控制器最终依赖的是动作价值的相对排序来选择最优的附加驻站时长，绝对数值的整体平移或发散并不会直接破坏动作选择。

[P1256 M001106,M001107] 为从实证机理上回答“为何降低价值网络的常规均方回归误差并不必然改善驻站控制回报”、“为什么直接微调绝对Q值会损害泛化性”以及“RE-SAC为何要引入集成成员去均值聚合与下置信界（LCB）保守评价”，本节在保存的公交运行状态 $s$ 下开展三组受控仿真诊断实验。参考动作价值 $Q^{ref}(s,a)$ 由重复仿真轨迹在完全相同的后续随机种子下运行至当日结束所得的折扣回报均值给出。三组受控诊断实验的具体设置与结果如下：

[P1257 M001108,M001109,M001110,M001111] 第一组实验（改变后继价值聚合目标的影响）：将自举更新中的滚动最小值目标改为滚动均值目标，在192个新公交状态上评估所选动作引发的9,216条后续仿真轨迹。实验发现，将滚动最小值目标改为滚动均值目标虽然减小了绝对MSE，但其中高达 $99.889\%$（自动调温组）至 $99.998\%$（固定温度组）的MSE改善完全源于不改变动作排序的状态共同偏移 $({\bar{e}}_{Q}(s))^{2}$ 的缩小，而在决定动作排序的动作相关误差上毫无贡献，最终两类后续仿真回报反而全线下降（自动调温下的系统回报平均下降 $10.742$）。

[P1258 M001112,M001113,M001114,M001115,M001116,M001117] 第二组实验（直接拟合动作价值差 vs 拟合绝对动作价值）：在56个拟合状态、2,688条首步动作分支上经过8,192次梯度更新，对比直接回归同一状态内的动作价值差（优势）与回归绝对动作价值。结果表明，虽然绝对价值拟合和动作价值差拟合均能显著降低训练集损失，但在未参与拟合的独立验证运行日上，相对于初始估计的平均决策遗憾（即所选动作相对于候选集最佳动作损失的目标价值）在自动调温下由 $3.007$ 反升至 $3.292$ 和 $3.596$，在固定温度下由 $2.831$ 反升至 $3.837$ 和 $4.385$。这表明在小样本局部状态上过度追求Q值绝对数值拟合精度易引发过拟合，难以转化为未见运行日上的泛化控制收益。

[P1259 M001118,M001119] 第三组实验（动作选择时网络输出去均值后聚合）：不追加任何网络训练，仅在决策阶段先从每个价值网络成员对各候选动作的估计值中减去该成员在当前状态下的平均估计值（消除各成员自身的基线偏移 $c_{k}(s)$），再跨成员取最小值选出动作，在192个新状态上评价4,112条后续轨迹。由于不同价值网络成员各自的常数基线偏移不一致，直接跨成员取最小值会使基线偏低的成员主导排序；而先在每个成员内部减去其状态均值再行聚合，无需任何额外训练即在自动调温与固定温度下全面提升了软回报与系统回报（固定温度下系统回报提升达 $+ 9.938$）。

[P1664] 3.4.6 长沙多线路场景验证

[P1665 M001460,M001461,M001462,M001463,M001464,M001465,M001466] 为检验RE-SAC相对于标准SAC的改进在依据真实城市公交资料构建的复杂多线路共线走廊中是否依然成立，本节在长沙市6条双向公交线路（7、102、122、311、406和705路，共12个运行方向）的快速公交仿真场景中开展算法横向验证。单回合运营评价时域为 $18,000$ 秒，状态输入采用表2-4定义的15项运行观测量并进行无量纲归一化，无有效同线前后邻车参照的边界事件（如首班车）不施加驻站控制。实验在完全相同的任务接口、类别嵌入结构、学习率（$10^{- 5}$）与小批量大小（$2048$）下，直接对比完整RE-SAC（$K = 10,\ \lambda_{ale} = 0.01,\ \beta_{ood} = 0.01,\ \beta_{lcb} = - 2,\ \beta_{bc} = 0.001$）、标准SAC（$K = 2$，上述四项正则系数全为 $0$）以及 $K = 10$ 下仅保留权重范数项或仅保留集成分歧项的消融配置。每种算法分别在车头时距目标（采用式(3-9)～(3-10)的多线路计划间隔奖励）与乘客时间成本目标（采用式(2-34)的同车区间乘客时间奖励）下独立训练100回合（使用两个独立训练随机种子）；训练结束后固定策略参数，在基准需求（1.0倍需求）、单次5倍冲击、重复5倍冲击、持续5倍需求、持续10倍需求及短时50倍需求共六类客流条件下各评价3个共同运行日，先在同一训练重复内对六类条件与评价日等权平均，再跨两次独立训练汇总。实验结果清晰地展现了多线路场景下算法性能与优化目标的对应关系：

[P1666 M001467,M001468,M001469,M001470,M001471,M001472,M001473,M001474,M001475,M001476,M001477,M001478,M001479,M001480,M001481] 在车头时距训练目标下，完整RE-SAC显著优于标准SAC基线及两个单正则消融配置：RE-SAC每次决策事件的平均奖励达到 $- 101.43$（原始值 $- 101.428$），较标准SAC的 $- 113.88$（原始值 $- 113.884$）提高 $12.46$；全网平均计划间隔偏差由SAC的 $106.47\text{ s}$ 降至 $101.47\text{ s}$（净减少 $5.00\text{ s}$），前后车头时距不均衡度由SAC的 $126.79\text{ s}$ 降至 $119.44\text{ s}$（净减少 $7.35\text{ s}$）。与此同时，在相同 $K = 10$ 集成下，仅保留权重范数项与仅保留集成分歧项的消融配置平均单步奖励分别为 $- 103.55$ 和 $- 134.51$，均不及完整RE-SAC（$- 101.43$），再次印证了多线路复杂场景中两类不确定性正则项协同作用的必要性。

[P1667 M001482,M001483,M001484,M001485,M001486,M001487,M001488] 在乘客时间成本训练目标下，采用固定保守系数的RE-SAC在复杂多线路及多档非平稳冲击汇总下尚未取得相对于SAC的平均成本优势：跨六类客流条件等权汇总后，RE-SAC与SAC的人均广义时间成本分别为 $15,710.36$ 秒与 $15,680.72$ 秒（其中在1.0倍基准需求下分别为 $11,443.91$ 秒与 $11,383.84$ 秒，在短时50倍极端需求下分别为 $21,025.42$ 秒与 $20,999.59$ 秒）。这一结果可能与以下两方面有关：一方面，多线路共线与换乘场景下同车相邻决策区间奖励具有较高的跨线干扰方差，RE-SAC全程施加固定强度的集成分歧惩罚与无缩放目标更新，在1.0倍基准需求下易使策略偏向保守而限制了换乘大站的驻站协调幅度；另一方面，测试集包含了高达5倍、10倍乃至50倍的非平稳突发客流冲击（10倍持续需求下全网生成乘客达 $969,621$ 人，远超既有389个班次的物理运力极限），固定保守策略缺乏奖励尺度自适应缩放、在线条件识别以及分布外动作响应约束机制。这一局限直接构成了第4章引入训练稳定化、近期统计反馈识别与因果符号约束（BAPR与CS-BAPR）以攻克多线路乘客时间成本优化的现实动因。

[P1668] 3.4.7 实验结果综合讨论与适用边界

[P1669] 综合本章双向单线路与长沙多线路场景的实验结果，可对车队共享表征与RE-SAC算法的增益来源及工程适用边界总结如下：

[P1670 M001489,M001490,M001491,M001492,M001493,M001494,M001495] 第一，车队经验共享表征与双重不确定性正则的控制增益。在平稳随机运行及车头时距控制目标下，类别嵌入共享策略与RE-SAC取得了显著的控制改进：多线路场景中RE-SAC相较于SAC使平均计划间隔偏差减少 $5.00\text{ s}$、前后车头时距不均衡度减少 $7.35\text{ s}$；单线路场景同一RE-SAC学习器下，可学习类别嵌入相较于独热编码使三类条件的人均广义时间成本降低 $1.41\% \sim 5.51\%$、时距不均衡度降低 $32.79\% \sim 37.74\%$，相较于同参数量的屏蔽类别组在基准需求（1.0倍需求）下亦显著降低成本 $2.32\%$。同时，仅保留集成分歧项在单线路500回合与多线路实验中均发生严重退化（单线路评价回报 $- 863 \times 10^{3}$、多线路单步奖励 $- 134.51$），而完整RE-SAC全程保持稳定，证明权重范数正则与集成分歧惩罚有效抑制了第3.1节指出的两类价值估计失真。

[P1671 M001496,M001497,M001498,M001499,M001500,M001501] 第二，长周期训练退化的熵温度诱因与动作价值误差分解规律。长期训练诊断表明，自动熵温度由 $0.441$ 衰减至 $0.095$ 并诱发边界动作比例升至 $0.40$，是造成500回合后期性能回落的重要原因，第100日冻结温度的配对干预可使后期回报显著提升 $8,939$（95%置信区间 $\lbrack 1915,15963\rbrack$）。价值误差分解诊断则证实，唯有扣除状态共同偏移后的动作相关误差才影响驻站动作选择——滚动均值目标虽减小绝对MSE，但其中 $99.889\%$ 以上源于不改变动作排序的共同基线平移，因而无法提升控制回报；评价价值学习改进必须以执行后的真实交通服务指标为准绳。

[P1672 M001502,M001503,M001504,M001505,M001506] 第三，训练奖励目标、集成规模与运力供给的工程边界。首先，控制收益严格依赖于训练目标与测试环境的匹配：单线路相同集成结构下采用乘客时间成本目标时，在线分歧正则可显著降低人均广义时间成本（降幅 $4.02\% \sim 14.20\%$）；但在包含极端非平稳需求冲击的多线路测试中，固定保守强度的RE-SAC在乘客时间成本目标下未能超越SAC，说明车头时距目标下的优势不可直接外推为非平稳场景下的乘客时间优势。其次，价值网络集成规模并非越大越好，$K = 5 \sim 20$ 已足以提供稳健的分歧估计，继续增至 $K = 40$ 无益于控制表现但增加训练显存开销；而得益于演员评论家解耦架构，在线部署仅调用单一策略网络，CPU单次推理耗时恒定在 $0.41 \sim 0.44$ 毫秒。最后，驻站控制本质上是在既有班次之间重新分配时间间隔，无法创造额外运力供给——当客流需求远超车队运力或车内载客已十分拥挤时，强行追求车头时距对称均衡反而会推高车内乘车时间（如表3-2均衡规则使总时间反增 $1.12$ 分钟），在途驻站必须与合理的发车频率配置相配合。

[P1673] 3.5 本章小结

[P1674] 本章面向尚未预先获取目标运营环境历史运行数据、客流到达与道路通行统计规律保持平稳但单次运营实现具有显著随机性的基础场景，研究了双向按时刻表排班公交车队的沿线逐站驻站控制问题。针对双向时刻表跨班次周转下全天主力车与高峰支援车交互样本规模悬殊、独立智能体策略难以充分收敛的结构性矛盾，本章通过构建同车跨班次纵向状态转移连接与可学习类别特征嵌入，将车辆服务标识、站点空间次序、运行方向及运营时段映射为低维稠密表征，使全车队得以在共享同一套策略与价值网络参数的同时，精准区分早晚高峰商圈大站与平峰末端站点的异质客流背景。针对逐站序贯决策中车头时距方差随站点推进累积放大、进而诱发自举价值目标随机噪声污染与未知驻站动作认知高估的双重失真机制，本章提出的RE-SAC算法在冻结单步惩罚保持算子 γ-压缩映射性质的理论保障下，利用目标网络权重范数正则约束后继价值函数对随机状态偏移的敏感度，并协同利用目标与在线价值集成分歧惩罚压制经验稀疏区的高风险驻站动作，筑牢了平稳随机运行环境下的动作价值评估基础。

[P1675] 围绕公交驻站控制的交通物理机理与价值学习规律，本章通过解析推导与受控诊断揭示了车头时距均衡与乘客出行时间成本之间的内在权衡关系。局部解析分析与仿真验证共同表明，单次附加驻站仅在既有相邻班次之间重新分配服务间隔而不创造额外运力供给；当车厢内已载乘客规模较大而站台新增到达客流有限时，机械追求前后车头时距对称均衡会使驻站时长越过成本平衡临界点，导致车内乘客额外付出的等待时间超过下游候车时间节省。相应地，在奖励函数设计上，本文提出的计划间隔奖励克服了传统指数型时距均衡奖励在对称晚点截面上无法识别整体偏离运行计划、以及在大偏差死区梯度消失的缺陷；而在价值估计层面，误差正交分解证实，动作价值估计误差中仅与状态相关的共同基线偏移并不改变候选驻站时长的相对优劣排序，唯有通过集成去均值聚合与下置信界保守评价压缩动作相关相对误差，同时约束长周期训练中熵温度的过度衰减以防止0秒或60秒边界动作饱和，方能切实提升驻站决策质量。

[P1676] 在双向单线路与长沙市6条双向骨干线路组成的共线走廊仿真验证中，上述车队经验共享表征与双重不确定性正则机制展现出显著的控制优势：同一RE-SAC框架下，可学习类别特征嵌入相较于传统独热编码与屏蔽类别输入，在基准需求、客流激增及运行模式切换场景下均大幅改善了前后车头时距均衡性并降低了乘客广义时间成本；在长沙多线路车头时距控制目标下，完整RE-SAC使全网平均计划间隔偏差与前后车头时距不均衡度较标准SAC分别减少 5.00 s  和 7.35 s ，且消融实验证实移除权重范数正则或集成分歧惩罚中的任意一项均会导致控制性能显著退化。然而，本章方法建立在外部客流与路况基础统计规律平稳的前提之上，全程采用固定强度的保守评价系数；当多线路公交网络遭遇大型活动散场或通勤模式切换等数倍乃至数十倍的非平稳客流冲击时，固定保守强度的RE-SAC难以兼顾常规时段调节效率与突变时段状态外推稳定性，尚未能在多线路乘客广义时间成本目标下取得相对优势。

# 文献、编号、符号与证明衔接校订报告

## 一、总体判断

这次检查的对象是实际用于生成Word的七章正文、中英文摘要和数学附录A至E，不是早期提纲或未纳入的研究材料。修订直接进入论文源稿和Word构建流程，未修改原论文项目、实验数据或实验结论。

原稿的主要问题不是“参考文献没有进入正文”：153条文献原本都能找到正文引用。真正需要处理的是引用的语义落点、方法来源在具体推导处的交代、部分术语评述，以及由多篇研究合稿带来的数学记号冲突。公式未编号则是全篇性的排版与追踪问题，原有372组独立公式均受影响。

本轮统一编号、补充实际引用、修正术语、整理符号说明，并将正文中的方法结论与附录中的具体命题连接起来。没有为了增加数量而补入新文献，也没有删除不利实验或把参考文献改写成对本文实验收益的背书。

## 二、参考文献与正文用途

### 2.1 已核对及保留的部分

当前153条文献全部有正文落点。公交停站、发车与协同控制文献主要支撑第1.2.1至1.2.2节的研究背景；价值学习、非平稳适应、离线学习及世界模型文献分别对应第1.2.3至1.2.5节，并在第2至6章的方法论述中再次使用。这种安排本身正确，不应为了“每章都有很多参考文献”把同一组来源机械重复到各章结论。

论文已有公交结果、已有研究的通用框架、本文的公交适配和新补实验分别陈述。MuJoCo平台来源不能证明本文的MC-WM收益；H2O+通用框架论文也不能替代本论文公交控制器的比较结果。跨章引用按这一原则检查。

## 三、数学记号及定义

### 3.1 统一方式

正文前增加“主要符号说明”，集中列出贯穿各章的公交量、决策量、网络参数、数据来源和误差量；每个方法新增的局部变量仍在公式附近定义。主要冲突按下表处理。判断符号是否相同要包含上下标和字体：例如物理停站与归一化动作不是同一个数值，不能为了字面唯一而抹掉动作编码；求和哑变量也只在各自作用域内起作用。

| 对象或冲突 | 修订后的区分 |
| --- | --- |
| 物理停站、归一化策略输出与抽象动作混用 | 物理秒数用$u$，归一化编码用$a^{\mathrm n}$，一般决策模型动作仍用$a$；在第2.3.4节给出对应 |
| 班次、车辆、站点及时间类别 | 保留车辆$b$、班次$j$、站点$i$；类别输入采用带意义的下标，避免与动作或模式冲突 |
| 站点服务时间与信念、车辆索引混用 | 上下客服务、道路行驶、驶离等待分别用$d^{\mathrm{svc}}$、$d^{\mathrm{run}}$、$d^{\mathrm{exit}}$ |
| 车内时间与状态价值都用$V$ | 车内时间改用$T^{\mathrm{ride}}$，$V$用于状态价值 |
| 队列人数与动作价值都用$Q$ | 候车人数用$N_{\mathrm w}$，$Q$用于动作价值 |
| 环境模式与类别嵌入都用$z$ | 模式用$z$，嵌入后的输入用$z^{\mathrm{emb}}$ |
| 终止标志与模式、惩罚量重名 | 终止标记统一为$d^{\mathrm{term}}$ |
| 熵温度与停站或其他参数重名 | 熵温度统一为$\alpha_{\mathrm{ent}}$；IQL分位参数和误差尺度各用专门下标 |
| 在线集成标准差跨章异名 | 统一为$\sigma_Q$；目标评价器方差仍为$\Gamma_{\mathrm{epi}}$ |
| 方差与标准差被直接写成平方关系 | 明确分别来自目标网络和在线网络，不将两个不同网络统计量等同 |
| 奖励函数、评论家参数与模型预测奖励混用 | 奖励形状函数采用$g_h$；评论家参数保留$\phi$；期望奖励$R$与实际奖励$r$分别定义 |
| 车头时距与输出映射都用$h$ | 输出映射改为$f_{\mathrm{out}}$，正文与附录D同步 |
| 线路索引与环境索引都用$\ell$ | 线路保留$\ell$，源目标环境索引用$\iota$ |
| 源目标下标有两套写法 | 正文及附录E统一使用$\mathrm{sim}$、$\mathrm{tgt}$ |
| 源预测状态增量与物理停站都使用$u$ | 源预测增量改为$\widehat f_{\mathrm{sim}}^{\Delta s}$ |
| 固定惩罚即时项与信念都使用$b$ | 惩罚后的奖励用$R_{\mathrm{pen}}$，信念用$\rho$，联合信念另有明确上标 |
| 初始旧/新概率比与后续新/旧概率比同名 | 初始旧/新比为$\Omega_{\mathrm{prior}}$，第$n$步新/旧比为$O_{\mathrm{belief},n}$，明确第零步为倒数关系 |
| 稀疏模型系数、批量大小和支持掩码缺少区分 | 分别为$B_{\mathrm{coef}}$、$B_{\mathrm{batch}}$、$m_{\mathrm{sup}}$ |
| 保守、约束与反馈系数重名 | 使用$\lambda_{\mathrm{cons}}$、$\lambda_{\mathrm{con}}$、$\lambda_{\mathrm{fb}}$等对象明确的记号 |

网络参数、时间和坐标维度、积分人数、误差上界、模型选择集、动作截断、终止标记及置信权重等原先交代不足的量，均在相关段落补入定义。改动没有改变算法参数取值、实验预算或结果表的数据。

### 3.2 缩写与名称

中英文摘要各自按独立文本处理；正文首次介绍方法时给出全称及简称，后续以简称为主。重点补足SUMO、MDP、HiP-MDP、UP-OSI、PEARL、VariBAD、RMA、CS-BAPR、SINDy、IRM、CVaR、离线学习方法组、世界模型方法组以及CPU、GPS、OD、AUC、RMSE、LQR、TV和KL等。人名、软件专名以及本身没有官方展开形式的方法名不人为创造英文全称。

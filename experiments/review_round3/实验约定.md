# 两轮评审的剩余实验补充

2026-09-29冻结。代码仅在本目录开发，原论文项目、历史结果和原比较协议不改写。串行开发，独立任务在Linux服务器并发执行；评价按一个运行日一个任务拆分。

1. **世界模型机制**：沿用完整适配的3个训练种子、3种源标定场景、50000次离线初始化和25000个源事件。比较原混合学习、0.75倍真实样本TD损失、0.75倍真实损失加0.25倍模型损失。每组共同的新评价日，两个需求水平。模型组记录未加权预测损失、局部置信度、归一化尺度、残差贝尔曼值、权重与有效样本量，以及真实/模型损失的评论家梯度范数和夹角；诊断不更新参数、不消耗训练随机数。模型验证集用于既有模型选择，不称独立确认集。
2. **集成规模**：K=2、5、10、20，各5个全新训练种子、100回合，其余最终RE-SAC设置固定；共同评价正常与快速切换环境。记录训练和推理成本，不宣称普遍最优K。
3. **奖励运营目标**：复用4种奖励、3个训练种子的既有最终检查点，不重训；新增有效邻车的计划车头时距偏差、始发晚点、单程运行时长与终点周转，与乘客时间和完成率并列。输入没有逐站到达时刻表，不补造逐站晚点，也不把单程时长称为周转时长。不能把自身回报作为总体优越性的证明。
4. **关键状态响应**：源仿真与SUMO均执行0、20、60秒固定停站，在共同需求档位下分低载客、无后车、晚时段报告转移响应。跨平台不是同一个微观状态，分别报告状态组成与条件响应；不将分组相关性称为单次干预因果效应。
5. **执行保护服务链**：既有混合、离线、源学习及零停站策略交叉有/无完成保障，记录触发时刻、车辆、站点和关联乘客的上下车与窗口内成本。配对比较完整策略日；乘客与触发的关联分析不冒充单次保障触发的独立因果效应。不延长24000秒窗口，不安排末端清空或实车试验。
6. **比率诊断**：短预算已有完整检查点就地读取；同预算配置此前仅保存策略，按原配置重跑混合参照并保存比率网络。使用原代码按完整需求实现与源回合划分的分类器留出集，只诊断、不更新策略或分类器，报告分类性能、权重分布、截断比例和有效样本量。该留出集未参与分类器拟合，但参与过演员和价值学习，不能称整个控制方案的独立确认集。
7. **成本与正文**：汇总保留的开发、失败、训练和评价记录，明确历史缺失范围，不能靠重跑伪造历史总账。补充结果出齐后再更新正文、图表与Word；实验尚未完成时不写成已解决。

所有比较先在运行日内配对，再在训练种子层汇总；固定策略服务链以运行日为重复单位。保留全部方向，不按结果追加预算或挑选检查点。远端仅回传紧凑JSON/CSV汇总，模型、回放和逐乘客记录保留服务器。

实现核查补充：同预算程序逐日新建采样器，随后重写回合编号，但未重算源分类器留出标记，故其现有源缓冲区不能作为留出集。本轮不改变该训练过程；训练后按39701—39703三个新种子分别采集冻结策略源运行日，完全不做梯度更新。目标部分仍使用原分类器留出需求实现。该安排修补的是诊断独立性，不追溯改写旧实验定义。

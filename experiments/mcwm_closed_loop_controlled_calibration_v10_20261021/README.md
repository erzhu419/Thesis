# v10 受控动作校准小试

两个开发种子 6201/6202 × 稳定/局部冲击，共 4 日；每个完整日保持 50000 更新的原初始化、32768 历史样本、4096 source 样本、24000 秒原生目标时长，以及 57×5＝285 个训练记录名额、456 次策略更新。所有调度任务固定 `high`。短预检使用原初始化，缩短 world 拟合和观察时长，只验证接线。

每个 300 秒窗口，诊断站首个合格三线路事件执行 0 或 7.5 秒。两动作必须都能通过原 F 真实执行；各线路按实际成功次数消费固定随机的低/高平衡块，空窗口不消耗动作。原 completion floor 不放宽，失败与缺失保留。

校准记录最多占每个反馈包一个名额，普通 global 样本补足其余名额。每条校准记录分别记录下一全局事件、同车同 trip 下一站、精确 300 秒系统乘客账本；全部端点完成后再延迟 30 秒释放。同车端点从实际动作 issue 记到下一站事件交付，两端使用原生账本；事件检测时间另存，因为原生桥检测后还会完成一个 tick 才交付。三个响应字段属于同一条受控记录，不展开为三个 replay 样本。零时长 global 保留原值，仅解析推进，实际 learned-global 数单列，端点模型的 global 斜率也仅用正时长行拟合。

新轨迹是 base、58 列 global 对照和 13 列端点模型的共同前缀。58 列保留 v9 的 memory_level 设计，拟合所选正时长 global 事实；端点模型只拟合所选完整受控记录，三端点分别建模。物理协变量使用原 102 条 source 区间，不额外使用未计入预算的 target 区间。两个响应候选均被动，原 action_model 的 trust 算法、模型 TD 比例和每包 8 次更新保持不变。

18000 秒后停止全部训练，剩余时段的受控记录只评估。每条预测在 issue 时保存，禁止用后来拟合的模型回算成绩。汇总按线路、稳定/冲击、训练前后与停更后分层，零时长独列，比较覆盖、设计秩、真实执行动作的预测误差和解析前后的动作斜率。只比较新轨迹上的同一批记录，不要求复现旧版前缀，不把旧分支真值加入训练。

本轮先判断受控动作覆盖和响应端点是否有效。没有新增成对原生分支；随机动作组的成本差是描述统计，真实执行动作的误差也不是同状态低/高收益真值。13 列小模型的动作斜率按线路固定；本轮不声称已学会状态依赖排序或改善候选策略全日控制。独立确认尚未提交，必须先审阅本批结果再决定。

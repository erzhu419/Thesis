# 上下文滤波修复诊断

本批独立于固定TD探索，不训练公交策略，不改旧实验或论文。共4个单核CPU任务：两个交叉种子、完整8项与三项物理摘要。模型只由另一种子的固定策略源转移块拟合，在本种子原识别策略生成的轨迹上评价。

预先固定比较原递归滤波、1/4/16块平均高斯证据；每种均保留不回退及评分差小于0.15时回退到原开发集最佳统一系数的版本。平均证据不随窗口长度增加而放大评分。完整报告各类准确率、高分误判、接受比例及系数误路由偏差，不以本批留出结果选择窗口。

原日志虽未保存重置标记，但逐块保存了belief。通过原模型和原公式核对“沿用上一块belief”与“重置为均匀belief”两种更新，恢复重置位置。恢复必须匹配完整轨迹；原8项递归滤波还要重新复现全部已记录belief，才可用于配对比较。该步骤是离线恢复回合边界，实际窗口滤波只使用已完成转移块和环境重置事件。

## 完成结果

5项实现测试通过，4条CPU任务t108828至t108831全部完成。六条源轨迹均恢复出一次回合重置，原8项递归滤波的全部belief精确复现，最大残差为0。

下表为三个类别等权、两个交叉种子等权的结果。“高分误判”是错误且最大评分超过0.9的块占比。

| 方法 | 8项准确率 | 8项高分误判 | 3项准确率 | 3项高分误判 |
| --- | ---: | ---: | ---: | ---: |
| 原递归滤波 | 74.94% | 17.63% | 80.08% | 10.92% |
| 1块平均 | 76.80% | 0.00% | 76.53% | 0.00% |
| 4块平均 | 75.91% | 0.00% | 76.63% | 0.00% |
| 16块平均 | 75.10% | 0.00% | 77.38% | 0.00% |

三项摘要配合原递归滤波的中等偏差准确率为69.62%，原8项为53.17%；两个种子的整体准确率分别从74.04%、75.85%提高到78.88%、81.27%。较大偏差准确率为70.60%，略低于原8项的71.65%。这说明特征缩减与时间累积有交互，单块诊断的结论不能直接推到在线滤波。

窗口平均在本批消除了高分误判，但增加窗口长度没有一致改善。三项4块平均加回退后，63.02%的块继续采用场景混合系数；这些接受块的合并准确率为90.25%，全部块的分类准确率仍为76.63%。接受块准确率不是整体识别率，也不是公交收益。

回退未改善窗口法相对于旧场景映射的系数偏差。例如8项1块平均的平均绝对偏差为0.0410，加回退后为0.0386，原递归滤波为0.0231。窗口法的评分更分散，软混合也把系数推向中间值。当前保留三项递归滤波作为后续候选，同时保留全部窗口和回退的负面结果；策略训练需结合固定TD批次的系数映射结果另行安排。

## 局限

原轨迹由旧策略生成，滤波改变后的策略反馈尚未验证。三项物理摘要不是单车速度或实际停站残差；评分未经概率标定。系数误路由只是相对于原开发集映射的偏差，不是公交控制收益。旧映射的跨种子稳定性另由固定TD批次检验，本批不读取SUMO结果。

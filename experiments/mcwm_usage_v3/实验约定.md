# MC-WM模型使用机制：首轮开发试验

本轮检验网页诊断中的首要假设，不移植整套CFCMT或CS-BAPR，也不预先认定改动有效。原论文、已完成实验及当前博士论文结果均不覆盖。

两训练种子6201、6202复用各自50000次IQL初始化；正常标定、联合50%、75%源参数失配下比较H2O+、0.75倍混合损失、原MC-WM、归一化置信、固定0.5模型权重、归一化置信加源目标修正，共36条训练。另各训练一个纯目标日志IQL续训参照，共38条；纯日志策略没有源条件，不重复训练为三个独立参照。每条策略在两档目标需求、五个新共同环境块评价，共380个24000秒运行日。

沿用完整日程的25000源事件、5000预热、20000次后续策略/评论家更新、15000事件处演员学习率缩小、模型三成员和刷新日程。纯日志参照同样新增20000次IQL更新，不采源经验。所有方法执行相同停站变换和完成保障，目标SUMO只作最终评价。固定权重组保留同样的置信网络训练开销，但实际模型损失权重恒为0.5。

联合75%设置速度0.25倍、OD与基本停站时间1.75倍、额外路口密度0.75；这不是转移概率距离75%。速度观测档案最高需求档为1.25，高需求源条件仍按既有做法使用该档观测速度分布，物理客流和道路干预按上述参数执行。正常标定H2O+作为现有标定的参照，不冒称本轮实现了自动离线标定或DROPO。

归一化置信只把备份中的即时项改为(1-gamma)乘log c，gamma仍为0.9；固定局部置信、无终止时权重固定点由c的10次方改为c。模型误差的尺度、损失系数及拟合目标不改变。固定权重对照用于区分恢复更新幅度与状态相关排序。

源目标修正只作用于训练混合批内的源物理转移：非终止、非批内零时间，且时间小于运营窗口的0.75。使用目标模型在相同源状态动作上的预测构造标量贝尔曼目标，以归一化置信混合原源目标与目标模型目标；不平均离散事件或槽位。当前事件所属线路相同，且标准化当前事件状态动作到目标拟合样本的最近邻距离不超过目标停止块的95%分位数，才允许修正。该距离是经验支持判据，不是真实覆盖保证。未通过者、零时间批内转移及终止转移保留原目标，不宣称已完全消除有偏源经验。只改变评论家目标，演员的数据来源不变。

每1000次更新保留分项预测误差、长停站子集误差、局部置信、实际权重、梯度范数比/夹角及源目标修正比例。评价同时记录原始停站、幅度变换后停站、最终保障停站及保障覆盖比例，只存摘要。模型及策略权重只留服务器，小型JSON回收本地；训练用GPU，评价分散到六个192核CPU节点，每个运行日一个任务。

这是两个训练种子的开发筛查，不作正式显著性结论。高失配条件的首要观察为正常与高需求下广义时间、完成率及逐种子差值；5秒时间改善和完成率不降低超过0.1个百分点为预定实际量级参考，不据此隐藏反向单元。原MC-WM、匹配系数参照、纯日志以及正常标定参照一并保留。若权重恢复但控制变差，不继续凭性能加权重；若源支持比例很低，不将本轮说成源纠正成功。后续机制分解、自动标定及独立种子确认在读出后另立协议，不混入本轮结论。

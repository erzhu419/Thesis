# 冻结策略限幅验证

9组独立源探测、3组预检、36组闭环评估均完成，未新增训练。阈值只用1至3倍源需求及独立日期生成；原策略复现、未干预案例复现和旅客样本一致性检查通过。服务器汇总，仅取回约128KB结果及小阈值摘要，旧结果和论文未改。

人均广义乘客时间为两倍候车时间加车内时间，单位秒。各学习方案平均两次训练所得策略、三个相同测试日。

全日总量方案在持续10倍的6个配对案例均改善，平均减少44.70秒，完成率由约6.09%提高到6.40%，冲击窗口内原计划旅客成本减少83.76秒。两次策略的驻站由12.89、58.60秒降至2.15、23.46秒；常态及50倍场景12例完全不变。它是当前更稳定的候选，但仍比既有补状态版高30.49秒、比零附加驻站参照高30.09秒，不能说已经达到最优或全面胜出。

分时段及分线路方案中，第一个策略在持续10倍、50倍场景分别增加31.10、13.27秒，第二个分别减少71.42、31.86秒。平均改善掩盖了第一个策略的退化。后半程全网平均缩放比例降至约3%，而只按全网总量限幅在末期比例不可能低于约24.2%；分线路硬上界牵连了整个向量。源探测末期某条线路上界仅374人，说明单线路上界不能直接用作全网统一缩放的约束。

下一步保留全日总量候选，单独测试分时段的全网总量限幅，去掉分线路硬上界，仍先冻结权重。若闭环结果稳定改善，再考虑训练阶段的输入尺度调整。当前证据支持积压输入外推是可干预的退化机制，不证明全部训练问题已经解决；本轮是未启用NAU/SINDy的MLP诊断，不替代完整符号CS-BAPR的结论，零附加驻站也不是Daganzo规则。

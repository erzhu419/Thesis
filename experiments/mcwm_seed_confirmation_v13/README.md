# MC-WM 独立种子确认实验 v13

## 实验目的

区分算法的跨种子收益和开发集选择最终策略的收益。原有两个初始化不重复充作新增种子；本轮63001--63020各自从随机网络开始完成50000次IQL更新。同一种子的四种续训方法共享该种子的初始化。

## 固定设置

- 三种源域条件：已标定、中等偏差、高偏差。
- 四种方法：H2O+骨干对照、归一化MC-WM固定0.25、固定0.30、原共享上下文门控。
- 每项续训25000次源域交互，5000次预热，20000次更新；目标SUMO无在线训练。
- H2O+对照不训练世界模型，采用原始观测TD损失；模型方法保留0.75观测TD系数。
- 每个策略10个开发案例、10个独立测试案例，均包含两档客流。Daganzo/TransitDuet规则实现与车头时距规则使用相同案例，Daganzo规则沿用现有代理实现。
- 识别器沿用已冻结的两个提供者，按种子序号交替分配，不重新拟合。

## 选择与汇总

各方法、各源域条件只按完整开发集的平均广义乘客时间，从20个种子中选择最终策略；并列时选较小种子。选择写入后不再更改。全部种子的测试结果和开发集所选策略的测试结果分开汇总，保留退化结果。

## 执行

20项初始化、240项续训、4800项策略评估、40项规则评估，共5100项任务，另有结果回收任务。每项使用单线程CPU、零VRAM，可分配node001--node006，不固定节点。任务通过初始化和策略完成记录分阶段放行。

仅上传代码与小型识别器JSON。逐日结果核验、开发集选择和跨种子统计均在服务器完成；完整结果、训练日志、数据与权重留在服务器。本地只接收`analysis_summary.json`和`handoff_status.json`两份摘要文件，并据此更新进度和放行依赖，不递归拉取结果目录。回收入口失败时尝试其他共享目录入口。上下文最后修正分支v14单独提交、单独评估和汇总，不自动替换本批次方法。本文档及实验不修改论文正文。

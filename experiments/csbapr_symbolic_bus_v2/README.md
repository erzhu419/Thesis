# CS-BAPR 公交符号反馈补充实验

2026-10-02：20条正式训练、234条正式评估全部完成，配对结果与诊断见[结果分析](RESULTS.md)。

## 实验安排

正式训练为两种奖励、两个配对种子、五组配置，共20条独立的100回合训练；固定末次检查点，不按测试表现选择种子。训练种子64001、64002，测试种子74101、74102、74103。每个策略在常规、单次冲击、重复冲击三个场景各测试三个种子。

- `centered_symbolic`：去NAU、参考状态下的残差中心化、SINDy反馈、两项雅可比约束；critic正权重范数偏移为零。
- `uncentered_symbolic`：保留相同反馈与约束，移除残差中心化。
- `centered_no_symbolic`：移除拟合反馈及两项符号约束；时距目标使用Daganzo参考，乘客目标使用零额外holding参考。这是组件组合对照，不是单项损失消融。
- `legacy_nau`、`legacy_mlp`：调用原冻结公交入口，仅改为本批独立输出目录。

另评估直接SINDy反馈、Daganzo与零holding，正式评估共234条。全部任务单线程CPU，允许node001至node007自由调度，不占GPU、不绑定311节点。8个独立辨识日、短程检查、正式训练、评估及汇总共290个调度任务。

## 公交适配

参考状态保留当前线路、车辆、站点、时段、需求及计划背景，仅将前后车头时距置为计划间隔。中心化约束的是学习残差，不强制完整公交动作等于零；原动作映射中归一化零对应30秒holding。

每种子另采集4个无学习的运营日。前3日用于拟合，最后1日独立诊断；短程检查只使用第1日拟合。SINDy按线路识别同车相邻站点的受控状态增量及两种成本，再以两站常动作滚动预测生成平滑holding反馈。辨识数据及其成本单独记录，不计作两组旧配置已有的训练数据。

## 保存与分析

所有新权重、辨识数据和评估保存在服务器的本实验目录。`submission.json`记录本批任务；`summary.json`仅包含就绪信息、训练概况、配对均值和差值。服务器执行汇总，本地只回传该小型JSON。短程训练和评估通过后自动放行正式任务，测试仅等待对应模型或权重。

新算法源码来自CS-BAPR已完成的验证v8快照。本实验不改动正在更新的CS-BAPR、CFCMT、H2O+/MC-WM实验，也不覆盖旧结果或修改论文正文。

## 解释边界

压缩公交状态和稀疏反馈属于近似模型，不能视为完整马尔可夫模型或最优控制器；不沿用普通MLP的有限Lipschitz证书。乘客奖励是同车观测间全系统成本增量，区间可能重叠，运营评价另用单次全系统时间积分。本批是公交适配版本，是否有效须由本批结果判断，不能从随机载荷任务直接推断收益。

# 博士论文中文图件

本目录图件服务于《运行不确定性与模型失配下的公交在途学习控制方法研究》。使用Python/Matplotlib，依次运行 `python3 scripts/build_figures.py`、`python3 scripts/deepen_figures.py` 和 `python3 scripts/operational_figures.py`；原论文、实验与证明目录保持只读。

当前正文共46幅图：8幅研究路线与方法示意图、1幅解析作用图、1幅实际SUMO路网图、36幅既有输入、实验及运行数据图。第三、四章本轮增加停站作用几何、走廊小时输入、需求切换时序、独立测试发车执行和逐种子乘客时间分解。上一轮增加的六幅源目标运行与H2O+解释图继续保留。逐图来源、统计量及论证目的见 `figure_sources.json`，小型汇总值见 `source_data/`。图号以正文中的出现顺序为准，工作文件名不进入论文正文。

图件按146.05毫米宽绘制，以360 dpi PNG嵌入Word，另保留PDF矢量版和文字可编辑SVG。正文采用独立中文图题。结果图的标准差、置信区间与无区间的均值分别标注；训练验证曲线与最终测试结果分别使用。原表中已舍入的汇总值保持原精度，CSV中的数值不再提前舍入。

## 适用范围

SUMO用于高保真代理目标验证；真实运营一行表示应用延伸。第3、4章公交任务、第5章受控动力学实验和第6章多线路公交实验分别保留其条件。模型类别干预图同时保留收益不明确及违例差异的结果。概念图表达方法和研究关系，不表示所有模块已在同一公交系统中联合验证。本次依据既有数据绘图，未新增训练、修改原项目或从服务器拉取数据。乘客时间分解与分线路比较是原确认样本的事后解释，不是新的独立确认。

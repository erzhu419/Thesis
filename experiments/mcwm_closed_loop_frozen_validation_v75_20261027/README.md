# v75：冻结v73的新三种子独立验证

本研究按2026-10-27用户授权固定执行6206–6208三个新训练种子。v73算法和扩展信息契约不变，旧研究的稳定尾窗失败结论保留。新研究以全天乘客成本为主要终点，稳定尾窗完整报告。

先生成三份原配方50000步IQL初始化：完整3284718条离线训练数据、原V7 trainer/replay、2头256维、float32完整GPU缓存、原default编译及优化日程。采用原GPU环境PyTorch2.4.1和3080Ti；每份每10000步保存参数、Adam与RNG恢复点，初始化无模拟、无在线更新或ratio预训练。三份共150000步，独立于后续响应预算。

随后固定3种子×稳定／冲击×fresh／no_fresh，共12个24000秒整日。每个条件双臂同初始化、同外生种子并行；6206稳定首对的首包预检复用整日，通过后直接运行其余10日，不按成本正负筛选。六对完整前缀、实际并行、同初始化、F及预算均在汇总核验。

每个整日保持285条latest5协变量、57包，critic/V/actor/温度各456次更新；fresh另285条风险替换完整事实，仅recent30进入fresh critic。no_fresh只使用285条s/a，不保留新完整结果。实际交集、并集分别计数，fresh不同target记录上限342。采样器、原混合backup、CQL0.2、F和trust均冻结；停更后零训练。
